# 多矩阵主题分类与参考题型长任务

开始：2026-10-28。状态：已完成并在正式工作台启用。

## 目标与范围

补齐 AI、商业、消费、文化、财经、教育、地理、历史、产业、科学十个内容矩阵的选题分类、真实参考例题与可复用题型。ChatGPT 已有九类继续使用。所有内容矩阵每日默认参考库出题；联网发现保留为主动补充参考内容的入口，也可以由用户在设置中另行选择。

主题分类描述观众关心的问题，不再直接用日报、周报区分。它独立于现有制作栏目，通过已有 production 绑定继承声音、画面、倍速和包装。教育使用已有通用主题制作路径。每个矩阵初版提供八至九类，每类三种有领域特点的题型，例题取自已读的公开内容或既有采集材料。

## 阶段与交付

1. **盘点与设计**：核对矩阵受众、现有制作绑定、参考库和历史主题。整理分类表，保存旧分类的兼容入口；避免覆盖其他聊天正在打磨的内容栏目。
2. **参考内容整理**：浏览原作者、研究机构、博物馆、大学、产品文档等公开内容。按具体问题归类，保存实际标题、链接与简短的题型借鉴说明；旧材料用于学习问题结构，不用它声称刚发生的新动态。
3. **分类与题库接入**：新增 `config/theme_categories/` 与各矩阵 `config/theme_library/`。默认出题只使用当前分类；旧分类及其中的主题、例题和题型仍可查看、继续制作或按原题型出题。
4. **每日方式切换**：把现有十一份发现配置设为 `ideas`，缺省值同样改为参考库出题。沿用已有计划 ID、时间和开关。联网发现使用独立补充任务，不改变每日模式。
5. **界面与制作连接**：分类筛选、参考库、历史、手动命题及题型复用显示清楚。新的主题分类进入文稿上下文，同时继承实际制作绑定。每类最多一条，已用与历史去重继续生效。
6. **验证与启用**：隔离数据验证十个新题库的分类覆盖、题型与例题引用、矩阵边界和旧记录兼容；回归每日出题零搜索及手动联网发现；检查界面与配置。实际运行多矩阵生成，记录主题、分类、请求和搜索次数。正常服务加载遵循现有维护准入，不中断其他任务。
