| 输入图片与节目导航 | 口播会忽略空章节和空段落，但输入图片编排及导航仍按原始下标计数，造成错位、越界或空段落被选中 | 复用统一的有效口播章节、段落视图；口播、输入图片、自动截图、节目导航及节目清单使用相同位置，原稿保留 |

| 未采用素材复用 | 所有实时来源读取失败时，已有符合原有时间、次数和采用状态限制的素材仍可重提，但最终扫描数检查将整次采集判为失败 | 已实际交付的有效材料可以继续走原流程，原来源错误保留；没有材料时仍报读取失败，不伪装成无新题材 |
