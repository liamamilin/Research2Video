2026-11-01。用户要求修复 AI 补充快讯遗漏问候、节目导航的问题，并明确其他矩阵与任务应复用公共能力，不逐个任务加补丁。

## 公共修复

- 普通报告与助手材料改编都调用 `writer.write_for_column`，统一读取栏目问候、整期/单条模式、教程结构、原配方声音、段落参数与写稿字段。仍调用原来的作者一次，没有新增模型阶段。
- 新的材料改编/材料研究任务继承所绑定栏目的模式。显式选择的模式保留；原稿直出不插入问候、不改写原文。用户提供的创作标题继续作为材料任务的输入，不套上来源报告的日期标题。
- 旧材料任务若缺少冻结的模式，在下一次成功写稿时补齐；失败不提交模式变更。旧版本与旧 MP4 保留。材料视频的节目导航读取该版本保存的节目清单，避免新稿升级后给旧稿视频错误补上导航。
- 材料任务即使没有研究报告，也能使用 App 原有“重新生成文稿”按钮；确认文字与状态提示按实际材料类型显示。

这些规则按栏目配置执行，没有判断新闻标题、产品名或具体任务 ID 的分支。
