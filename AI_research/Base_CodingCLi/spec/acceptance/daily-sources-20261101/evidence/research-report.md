### 1. ChatGPT 双账号切换教程：网页加一个、手机切一个，聊天和订阅各归各

- **题材分类**：T03 使用方法与教程
- **一句话**：这一期帮观众在网页和手机端添加第二个 ChatGPT 账号，学会不退出登录就切换，并在开始对话前确认当前账号、聊天记录、设置和订阅各自独立。
- **核心角度**：不是讲注册、付款或套餐百科，而是解决「多账号来回退出登录太麻烦、又怕切错号」的具体问题：网页从账号菜单选 `Add account`，手机从 `Settings > Switch account > Add account` 添加；添加一次后直接切换，但两个账号的数据和订阅不合并。
- **目标受众**：同时有个人号和工作号的人；一个 Free、一个 Plus/Pro 想分开使用的人；手机上不想反复退出登录的人；刚用 ChatGPT、还没搞清账号切换入口的人。
- **具体材料**：
  - 网页端添加第二个账号：打开账号菜单，选择 `Add account`，登录第二个账号一次；之后在账号菜单里选择任一已登录账号即可切换，不需要退出登录。
  - 手机端添加第二个账号：进入 `Settings`，选择 `Switch account`，再选 `Add account`，登录第二个账号一次；之后同样从 `Switch account` 里选择账号。
  - 同时最多保留两个已登录账号；要加第三个，必须先退出其中一个。
  - 每个账号各自保留 chats、memory、files、settings、billing；切换账号不会合并这些数据，当前选中的账号决定你看到哪段历史、哪套设置和哪个订阅。
  - 移动端账号切换是逐步 rollout：如果 `Settings` 里没有 `Switch account`，不一定是操作错了，可能是移动端推送还没覆盖到该账号。
  - 手机端如果看不到 `Add account`，先检查是不是已经登录了两个账号；如果是，退出其中一个再添加。
  - 适用条件：网页和手机路径不同；界面文案以当前版本为准；公开指南说明的是操作路径，不保证每个账号立刻出现相同入口。
- **操作与演示**：
  - 演示方式：用公开指南截图和菜单路径示意，不登录个人账号、不录个人录屏，不声称作者已经亲测；具体菜单位置和图标待实测，以观众当前版本为准。
  - 网页端步骤：打开 ChatGPT → 点账号菜单 → 选 `Add account` → 登录第二个账号一次 → 再打开账号菜单，选择另一个账号切换。旁白自然说明：「先别退出登录，在账号菜单里选 Add account，也就是添加账号；登录一次，以后直接在这里切。」
  - 手机端步骤：打开 ChatGPT → `Settings` → `Switch account` → `Add account` → 登录第二个账号一次 → 之后在 `Switch account` 里选择账号。旁白说明：「手机上入口在 Settings 里的 Switch account；没有这个选项，可能是逐步推送还没到。」
  - 异常分支演示：`Settings` 里没有 `Switch account`，画面标「移动端尚未覆盖」；`Add account` 不见，画面标「可能已登录两个，先退出一个再添加」。
  - 切换后确认：看顶部当前账号名/头像；确认历史对话、记忆、文件、设置、账单入口都属于当前账号；开始新对话或使用与套餐相关的功能前，先停两秒确认账号。输出画面用「账号 A / 账号 B」示意，不用真实聊天内容。
  - 待实测：不同系统版本下 `Settings > Switch account` 的具体位置、`Add account` 隐藏条件、网页账号菜单的图标样式。
- **画面建议**：
  - 开场左右分屏：左边网页、右边手机，中间大字「不退出登录，切两个号」。
  - 网页路径示意：ChatGPT 页面右上角账号菜单 → 下拉菜单高亮 `Add account`；用公开资料截图局部放大，个人头像和账号名打码。
  - 手机路径示意：`Settings` → `Switch account` → `Add account` 三级路径用箭头串联；缺失入口用灰色「未显示」卡片配字「逐步推送中」。
  - 数据独立对照：两栏账号卡片，各列 Chats / Memory / Files / Settings / Billing，中间画「不合并」隔离线；切换箭头从 A 到 B，只有顶部账号名变化，两栏内容不变。
  - 检查动作：镜头停在顶部账号名/头像 2 秒，配字「先确认当前账号，再开始新对话」。
  - 收尾卡：一句「两个账号，各归各；要加第三个，先退出一个」。
- **获客作用**：培养兴趣。先让观众获得「不退出登录也能切」的即时价值，降低多账号使用摩擦；当观众发现自己需要一个工作号，或想对比 Free 与付费账号时，会自然关心「在哪个账号里使用或升级」。本期先建立「切换前确认账号」的习惯，避免在错误账号里找功能，比直接推销更自然；后续可接文件处理、提示词等教程。
