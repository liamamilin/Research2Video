# 2026-11-12 文稿回归

以 `script_versions.created_at` 的本地日期为准，只读查询实际 `state/video.db`。当日 18 个版本行，排除无口播正文的 `local_video` 导入《你说得都对-MV-v1》v1，通读其余 **16 篇、17 个版本**。16 篇各有生成 v1，另有一篇编辑 v2。下文按稿登记全标题、版本与稿件 ID 前缀。《12分钟173个来源，ChatGPT的调研能信吗》的现行稿是 v2，批准稿是 v1。引文来自对应稿件，来源对照使用本地研究报告。

17 个版本都以选项式互动收尾。值得动的地方是正文已经给出判据，结尾又把它改成站队，例如豆包与 Plus、Gemini 记忆、车机三篇。真正影响判断的条件在文中已有好例子，包括配额刷新后任务不会自行恢复、能力仍未上线、性能数字只覆盖特定输入规模。作者可以直接提出取舍、解释机制或做有依据的推测。涉及产品是否已经上线、特定数字的分母、第一人称是否亲历，属于原文能够支持的事实范围。本文做文稿审阅和本地材料对照，涉及安全题材只记录编辑判断及防护取舍。

## 1. Gemini 4 Carbon：$2 变 $4，/swarm 更烧配额 · v1 · 3b1f2b

“Carbon 月底翻倍，/swarm 烧配额”里的“一个半夜跑光的 swarm，第二天早上可能还在原地”让观众知道新能力实际会在哪儿卡住，保留。标题承诺算模型成本，开场却先讲自动化安全，结尾又说“先把这两处收窄，比追新模型更划算”，等于三次换主问题。若沿原题讲，Carbon 章已经有价格翻倍、配额消耗、暂停后不自动重启这条完整判断。若沿结尾讲权限与默认值，开场那条线已经能立题。正文还复述过多安全报告细节，提取受影响对象、修复状态及配置建议就能支撑结论。上游原话“成本比次优外部模型低 2 倍以上”算术含义含混，适合回到原对比口径再讲具体比例，别用这句话扩大结论。

## 2. 一个 issue 就够到 npm 发布权？Codex 漏洞已修 · v1 · ef2446

“现在该动的是那一行配置”直接落到“它们是不是真的需要写权限”，给维护者一个当下能核对的判断。保留修复状态、公开报告没有报告恶意版本已发布，以及需要多个环节共同成立的信息。标题里的“一个 issue 就够到”与正文描述的多环节条件有张力。细节篇幅可以让给“回到开头那个陌生 issue——它能不能走到发布那一步，取决于你给了自动分拣多少权限。”末尾再问“还是先照旧跑着？”只让观众重选正文已经做出的选择。

## 3. Codex 自动分拣 issue，先把工作空间设成只读 · v1 · 27f82d

开头的“issue 正文是外部输入，不是你的指令”和结尾“令牌只给打标签够用的那一小圈范围”把原因和动作连上了。保留最小权限的判断。稿子又把扫几类可疑字眼写成日常做法，容易让观众误以为肉眼过滤足够。结尾“修完之后，它照样会把 issue 正文当指令读”也把需要读正文写成修复后必然把正文当指令，稿中材料没有给这一结论。删去两个推得过头的位置，已有的防护主张仍然成立。

## 4. 三天，近 100% kernel 自己写：Claude 搬上 AMD GPU · v1 · 149ec3

“CUDA 难绕开的地方在软件栈，不在芯片”说清迁移成本来源，“里面软件那一块要重算”是实质判断。“两边的钱都进来了”里“它要的不是站队，而是议价权”是可保留的作者推论，前面有多芯片布局和双方投资安排。三天只涵盖特定芯片上的提示词处理且出自路演，这一范围影响听众怎么使用数字，点清一次即可。末尾再次复述限定，再让观众“现在就动手往 AMD 上迁，还是再等一年”，把原先的重算预算夸成迁移决策。直接收在原文预算判断处更完整。

“老股东卖股票的钱，公司拿不到”和“卖芯片的、卖算力的、做代工的，都在这个价位上签了字”是稿内两处可展开的具体观察。标题把 1.4 万亿和“少一半”绑在一起，正文中“少了近一半”却比较约 1 万亿与先前 2 万亿传闻。1.4 与 2 的差距是三成，传闻用的股本口径稿中也未说明。标题和正文先把数字对应起来。“如果 Claude 上市之后真涨了价”既没有回应本文中最具体的融资结构，前文也明说招股书没有订阅价格信息。收尾可用原文“新发的进公司账上，老股卖的钱归那些股东”，或留在认购名单带来的产业观察。

## 10. 12分钟173个来源，ChatGPT的调研能信吗 · v1、v2 · 2045bd

**v1**：“先别被173这个数字说服”及“有几条真能支持报告里写的那句话”是有锋芒且具体的评价。“工单”章用两种模型答对同一道题、核对耗时不同的例子，说明答对和可用的差异。开头那段国内使用门槛提前打断标题的调研问题。“免费版ChatGPT对Claude”已经说“这次ChatGPT更接近能直接发”，前后又补“这不是谁永远更好”“测试者的偏好是他的偏好，不是排名”，两处补同一个口径。保留“这次”与少改一轮的理由就有分寸。“三周未回邮件”章把未读搜索拿来推算漏了多少未回复邮件，同时正文承认两者不同；上游把未读搜索和人工清单列为备选，本稿把前者写成单一基准会给错动作。

**v2**：逐段对比只移除了导读的使用门槛段，其余正文与 v1 完全一致。入题更快，免费版对比的重复限定、邮件基准问题与二选一结尾仍在。保留“错了能找回来”这个贯穿全稿的任务选择标准，足够作为结尾。节目估价和节目自述的测试范围在稿内已交代，保留这种归因。

## 14. 说梦话的人，多半没在做梦 · v1 · dd5385

“它说明不了你心里藏着什么大事”是能带走的判断，“一间一间屋子关灯”给读者清楚的机制画面。“我合租那会儿，室友老周凌晨两点”和“我表姐家孩子五岁”是亲历口吻，本地上游只有通用示例，没有这些人的亲历资料。原报告“误解三：说梦话就是做梦的时候把梦说出来了。”写快速眼动睡眠也可以说梦话、非快速眼动浅睡阶段也常见，未给比例；稿题“多半没在做梦”和正文“大多出现在浅睡眠”“做梦最热闹的那段反而少”把可能性写成了多数分布。保留可理解的情境和对梦话不能当真心话的判断，亲历和频率分布分别回到上游能够支持的范围。
