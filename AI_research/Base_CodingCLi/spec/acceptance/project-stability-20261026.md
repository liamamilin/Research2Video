# 项目性能与稳定性检查 · 2026-10-26

本轮覆盖研映前后端、出片队列、字幕、生成子进程和外接盘媒体读取。已有修改及业务数据保留，没有改写历史任务状态或重新发布视频。

## 已修复

1. **外接盘新出片失败**：迁移后 worker 传入物理路径，G2 仍限制路径必须位于本机项目内。最近三条任务因此在启动阶段失败。统一将已配置的顶层数据链接映射为稳定的项目路径，覆盖生成、创作配置、配音、字幕、前次计划复用及旧片视觉复用。任务内部越界链接和未配置的外部目录仍会被拒绝，制品清单沿用项目相对路径。
2. **引号导致字幕失败**：分句曾把句号后的右引号单独拆成配音段，强制对齐没有语音单元，最终报“短字幕缺少配音段”。新分句将闭合标点留在原句；历史标点段保留原字符和时间范围，无须改变原音轨。真正缺少有声段时仍失败，并显示具体段落 ID。
3. **视频分段播放重复读盘及内存峰值**：每次制品请求原来都会把整个 MP4 读入内存计算哈希。现在使用 1 MiB 分块，并在文件设备、inode、大小、修改时间及状态变化时间均未变化时复用哈希；缓存最多 256 项。覆盖同大小修改、恢复 mtime、原子替换及校验期间变化。
4. **唯一队列线程意外退出**：认领任务时遇到临时 SQLite/磁盘错误，或空闲音乐任务抛异常，原来可能直接结束唯一 worker。现在记录异常并退避重试；关闭时若线程尚未结束，继续持有独占锁，避免出现第二个队列消费者。
5. **首次页面脚本过重**：各页面及助手改为按需加载，页面模块加载期间侧栏继续可用。入口脚本由 685.04 kB 降至约 72.18 kB（约减少 89%）；这是入口文件大小，非全部资源或整体耗时的同比承诺。高级 YAML 编辑器仍是独立的大型模块。
