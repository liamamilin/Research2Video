## 共用切换链路

- 近期结果仅留在内存，最多 40 项、60 秒；重新进入仍立即请求最新数据。写操作前后和账号切换使快照失效，过期请求不能回填快照。测试覆盖重进、刷新失败、会话切换、写后迟到响应、过期和数量上限。
- 链路范围由布局统一读取，页头和内容共用，保持现有 5 秒轮询；更换链路会取消旧请求，同链路切换页面不清空范围。
- 实机从文稿 → 矩阵 → 文稿，保留 `chain=job-3dbaee773d34`；矩阵显示 1 个，文稿显示 7 / 7。已回到用户原文稿地址。

## 证据与边界

[接口对照](measurements.json)记录同一份实际数据的 3 次 GET 中位数。基准通过独立进程的 ASGI TestClient 运行，不启用 lifespan、后台 worker 或周期调度；基线在进程内加载 HEAD 源码，不回滚工作区。它包含响应序列化和压缩，不含真实网关、认证、网络和浏览器耗时，不能等同于页面打开时间。多个接口计算耗时没有改善或略有波动，本轮主要收益为矩阵查询精简、传输量降低和回访先显示已有结果。

助手的 WAL 问题由正式服务日志和页面错误发现；修复后通过原入口恢复历史对话。新增测试用 DELETE 模式的旧数据库验证迁移、保留历史和进程重启。

[页面截图](matrices-after.jpg)用于显示验证，不作为速度证据。原始基准脚本、日志、截图及失败尝试位于外接盘，经 `state/validation/tab-performance-20261121` 项目软链接访问。没有读取或保存浏览器 Cookie、密码或令牌。
