- 「能做什么」展示矩阵、信息源、研究、制作、批量操作、发布运营与系统管理的整体范围及可预填示例。

- `configure_matrix_task` 连接矩阵、共享来源、研究任务与兼容配方，保留其他字段和任务覆盖，返回准确生产配置标识。创建研究任务支持显示名称和来源引用，空关键词不再误用模板占位词。

- 调用仍经原生业务 API；后台按原账号复核角色，进程内部身份不能通过 HTTP 伪造，凭据不存入批次。
- 文稿/视频使用原 workflow，批次只协调前后步骤；结果按本批次文稿、版本和准确成片定位，恢复不触碰同一 workflow 的其他文稿。
