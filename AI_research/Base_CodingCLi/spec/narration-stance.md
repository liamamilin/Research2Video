# 口播先讲事情本身

2026-11-18。新稿要让观众听懂这件事、它怎么发生、结果会怎样变。影响理解或用法的条件留在对应的那句话里。研究和制作备忘不进旁白。材料里没有的细节，收窄或略去这个说法，并记在版本的 `narration_gaps`。不要把它表演成“我没有乱说”，也不要改写成“官方没公布”或“这项能力不存在”。

这条优先级用于之后生成、改写和润色的新稿。已经批准的历史稿、原文朗读稿，以及用户亲手保存的修改，保持原句。批准和出片不因为旧稿里的这类句子被拦住，也不会回头改那些句子。

## 优先级

1. 讲清事情本身、过程和结果。
2. 价格、日期、地区、权限、故障是否覆盖每一次请求、实验能不能推广到这组测试之外，这些会改变理解或用法的条件，直接说它会怎样改变结果。
3. 引用、教程里教用户写的句子，以及单独出现的“可能 / 尚未 / 不是 / 未验证”，都不是缺陷。
4. 取材备忘、自我免责、让观众替讲述者去官网核对，留在稿外。
5. 没有证据时，不说这个结论。备注只记录“口播略去了这句话”，不补来源，也不把缺口说成官方沉默或能力不存在。

## 离线测试能证明什么

`tests/test_narration_stance.py` 用假的模型回复走润色：模型若仍写自我免责，或改写成“官方没有公布”，都会被拒绝，然后收窄到上面的说法。模型调用失败、或根本没有可用模型配置时，同样收窄，并且不会把整篇删光。第二遍不再调用模型。引文和应保留的条件不会触发调用。

这不能证明真实模型下一次生成的稿子好听，也不能代替读一篇新的快讯或 T05。上线后的核对应只生成新草稿，不批准、不出片、不发布：各抽一篇快讯每条、快讯每天、T05 和 T09，读 `script_versions.sections[].paragraphs[].text`，确认上面的自我免责不再出现，价格、地区和故障范围仍在。不要为了这次核对重新生成媒体。
