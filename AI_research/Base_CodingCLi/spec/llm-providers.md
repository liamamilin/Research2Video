# LLM providers and the free-first fallback

状态：已实现（2026-10-19）。背景：Open Design（amr-link）账户配额和余额同时用完
（`insufficient_balance`，`coding_plan_exhausted`），10-24 才重置，临时切到了
opencode Go。这件事暴露了两个一直存在的问题：换一个服务商要手填三个值，填错一个
就打到别的厂商；换服务商会把上一个服务商的密钥覆盖掉，想切回去还得重新去拿。

## 服务商预设（`core/providers.py`）

一个预设 = `base_url` + 密钥存在哪个环境变量（`api_key_env`）+ 必需的请求头
（`extra_headers`）+ 已知能跑的模型（`models`，其中免费的列进 `free_models`）。
设置页「服务商」下拉选一个，三项一起填，不会出现「地址是 A 家、密钥是 B 家」
的错配。

**每个厂商有自己的密钥变量**（`OPENDESIGN_API_KEY`、`OPENCODE_API_KEY`、
`DEEPSEEK_API_KEY`、`OPENAI_API_KEY`），不再共用一个 `LLM_API_KEY`。几家的密钥
可以同时存在 `.env` 里，切服务商只是换读哪一个变量，不用重新填密钥，前提是
那把密钥曾经存过一次。`LLM_API_KEY` 仍然认，是旧配置的兼容名。

## 免费优先、付费兜底（`core/llm.py`）

`ai.model` 填首选模型；`ai.fallback_models` 是按尝试顺序配置的兜底模型列表，在
`model` 额度不足、权限被拒、模型下线、重试用尽，或返回
`finish_reason=content_filter` 而没有可用的完整结果时启用。普通网络抖动先重试
同一个模型；参数错误、工具协议不支持不通过换模型重试。`review_ai` 同样支持这两个字段。

过滤结果不保存成报告或文稿，也不修改素材或提示词。按配置顺序将原请求交给下一个模型，
每个被过滤的模型只尝试一次；全部失败时记录实际尝试的模型与原因。已经通过 `on_delta`
展示了正文的流式调用不会自动重播。文稿版本元数据保存实际回答模型和切换记录。

```yaml
ai:
  model: "minimax-m3.1-flash-free"
  fallback_models:
    - "minimax-m3"
    - "deepseek-v4.1-flash"
```

一次 `LLMClient` 换到某个付费模型后，这次任务剩下的调用都用它，不会每次都先
试一遍已知用不了的免费模型。换模型换到的那次请求，不计入原模型的重试次数，
重新给一份完整的重试配额。全部模型都报配额错误时，报错里会列出试过的每一个
模型。

设置页「AI 模型」卡片上，选中一个有免费模型的服务商后，模型 ID 下面会出现
免费模型的按钮，点一下就填进模型 ID；「兜底模型」是一个逗号分隔的列表。

## 切换服务商时的模型

设置页每张模型卡（AI、审校、报告清理、视频）会在浏览器里记住「这张卡上次在每家服务商用的模型」
（`ui/src/lib/modelMemory.ts`，连同兜底模型）。切到另一家时，放回那一家上次用的；没用过就清空，
不再猜一个。服务商的实时清单里没有的模型不会被记住。清空之后保存会被拦下（「还没选模型」），
否则服务端会把旧模型和新地址配在一起。记忆只在当前浏览器里，换浏览器就没有。

## 审校模型（`review_ai`）

审校（`spec/video-adaptation-audit.md`）可以配一个独立的模型，不配就和 `ai`
用同一个。两者结构完全一样（同一份 `_LLM_SECTION` 校验规则），设置页上是单独
一张可选卡片，没配置时折叠提示「视频文稿审校用上面的 AI 模型」，配置后可以
删除整节、改回跟随 `ai`。

2026-10-19 的现实情况：opencode Go 没有 amr-link 那种「唯一一个贵、强」的模型，
`review_ai` 暂时和 `ai` 走一样的免费优先策略，审校质量会比 10-24 恢复 Open
Design、换回 `deepseek-v4-pro` 之前低一些。

## 切回 Open Design（10-24 之后）

设置页「服务商」选回 **Open Design（amr-link）**，地址和密钥变量名会自动填好；
如果 `OPENDESIGN_API_KEY` 还没存过（这次切换前就没存过），在「API 密钥」卡片
粘贴一次。`ai` 和 `review_ai` 都要切。

## 模型检测与价格更新

AI、审校、报告清理和视频模型卡共用 `ProviderModels`。点击「检测并更新模型」调用
`GET /api/config/providers/{id}/models?refresh=true`，重新读取该预设服务商的 `/models`，
更新模型、免费清单和价格。同一家服务商在其他卡片里的清单同步更新；当前模型和兜底配置
不会被自动替换，点模型按钮才填入原始 ID，价格后缀不会写进配置。

服务端在 `state/provider-models/` 原子保存最近成功结果，普通加载缓存一小时，手动检测绕过缓存。
换密钥会重新检测。模型查询失败保留上次清单并提示；官网价格更新失败保留带原时间戳的参考价。
查询只读取清单与公开页面，不发送推理请求；列在清单中不代表当前账户一定有额度，需使用原有
「测试」按钮验证实际调用。

OpenCode [Go 官网](https://opencode.ai/v2/docs/console/go/) 和
[按量计费官网](https://opencode.ai/v2/docs/console/models/) 的价格表在运行时解析，
只匹配当前端点实际提供的模型。显示 `glm-5.3 (入 $1.4 / 出 $4.4)`，单位为 USD / 百万 tokens；
上下文或峰谷分档显示区间，鼠标悬停查看各档。Go 单价用于扣减订阅额度，月费另计。
免费列表来自零价条目和 OpenCode 已公开约定的 `-free` ID，不再依赖预设的静态提示。
Ollama 标记本地免费，硬件资源仍由本机承担。

## 已知的限制

- **部分价格未知**：OpenDesign 的公开价格页说明套餐额度，未提供可核验的逐模型 token 单价。
  当前未接入价格来源的服务商、官网没有列价的模型显示「价格未知」，不套用其他网关或原厂的价格。
  免费模型可能有地区、期限或额度限制；官网结构改变时会显示价格更新失败，等待修复或再次检测。
- **成本统计会在切换到付费兜底时失真**：`ai.pricing` 只按配置里写的那一个模型
  算钱，实际回答的模型换了之后，预算页的估算还是按免费模型的单价算（通常是 0），
  会低估花费。
