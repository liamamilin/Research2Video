## 路线

沿用现有平台管理的成片选择、发布包、任务队列与文稿发布记录。新增平台分别管理账号、任务、回执和能力；B 站已运行的投稿、首评、评论和数据采集保持独立。

1. 本地预检上传组件、依赖和回执契约（本轮）。
2. 实现抖音账号连接、结构化发布回执及公开状态核对，选择一条成片做真实验收。
3. 验收快手的相同链路，再开放多平台投稿入口。
4. 各平台的评论和数据单独验收后开放，不因上传可用就默认其他能力可用。

用户可选择同一成片向多个平台投稿，但应分别建立任务、保留各平台的发布包与结果。一个平台失败不覆盖其他平台的发布记录。

后续适配的完成标准：

1. 保存明确的发布响应或可核对的作品记录，取得平台作品 ID 与链接，确认账号归属。
2. 区分上传中、已提交、平台审核中、已公开和结果不确定；公开确认后才回写文稿的发布记录。
3. 网络超时、重启或未取得作品 ID 时进入待核对，不根据退出码自动标记成功，不自动重新投稿。
4. 仅按标题和时间找到的候选不能自动绑定；没有足够证据时要求人工核对。
5. 登录态按平台和账号隔离；短信验证或其他需本人确认的步骤暂停，保留任务状态。

在真实账号验收前，不能承诺已解决稳定取得作品 ID，也不开放出片后自动投稿。

## 抖音第一期实现（2026-10-25）

平台管理新增平台选择，B 站入口与原深链接继续使用原逻辑。抖音提供扫码连接、登录验证、手动投稿包编辑、独立队列和发布回执。当前支持手动投稿与可选作者评论；暂不启用出片后自动投稿、通用评论收件箱或数据采集。

账号连接由管理员发起，在本机专属 Chromium 窗口中扫码；二维码可在控制台查看。连接完成后再次请求创作者账号接口，确认 UID 和昵称，再保存本机登录态。控制台 API 不返回 cookie、token、浏览器存储或素材绝对路径。凭证文件权限为 0600，目录为 0700，存放于忽略的 `state/platforms/douyin/`；浏览器不连接或关闭用户的普通 Chrome。

投稿状态：

- 排队中 → 处理中 → 已投稿（取得平台作品 ID，尚未确认公开）→ 已公开。
- 确认公开并核对账号归属后，自动回写准确的文稿版本、成片、平台、链接及日期。
- 超时、异常返回或执行中断但没有可靠作品 ID：结果待核对，不自动重投。可以在创作中心核对后填写完整作品 ID/链接。
- 明确被平台拒绝，或确认没有提交：可手动重试。重试和开始执行前重新检查本版本是否已有发布记录。

浏览器适配器只允许一次发布 POST 穿过网络拦截层，响应中取得作品 ID 后先持久化，再结束上游流程，防止上游的重复点击循环造成重复作品。当前监测的发布接口是 `/web/api/media/aweme/create/` 和 `create_v2/`。这些网页接口可能变化；未知返回保留待核对，不推断成功。

回执接口结构参考 [AiToEarn 的抖音适配实现](https://github.com/yikart/AiToEarn/blob/main/project/aitoearn-electron/electron/plat/douyin/index.ts)，本地上传仍使用上述固定版 SAU。账号归属核对读取创作者最近最多 500 条作品；公开确认使用单独匿名浏览器中的作品详情，要求作品 ID、作者及明确的可见/审核字段匹配。缺少字段时继续待核对，不据管理页跳转或标题匹配回写文稿。作品数据结构及发布 POST 尚待真实投稿验收。

抖音队列为独立 `douyin.db`。后台独立检查线程每 5 秒推进；独立 worker 进程、持久任务和进程锁允许 Web 后台重启后继续查询连接/投稿结果。已接收的作品每 2 分钟尝试核对公开状态。B 站上传耗时不会阻塞抖音连接。

### 首评与置顶可行性复核（2026-10-25）

- 自动作者评论有浏览器适配路线。AiToEarn 的[维护方文档](https://docs.aitoearn.ai/zh/use/plugin-publish)明确提供按作品 ID 发送抖音评论的方法，可作适配参考；该次可行性复核时，项目尚未实现评论发送、评论 ID 回执与重复发送保护；其后实施及真实验收见下文。

抖音发布包现可选择「视频公开后添加作者评论」，最多 500 字。常用模板按抖音账号保存，可在每次投稿中修改或关闭；队列保存当次内容快照，修改模板不追改已有任务。已有投稿可在回执卡片显式添加一份作者评论，不会重新上传视频。抖音置顶选项禁用，并说明作者评论的展示顺序由平台决定。

作者评论为独立 `FIRST_COMMENT` 子任务：等待确认公开 → 等待发送 → 发送中 → 已取得评论回执 / 已发送并回读。评论失败不覆盖视频的发布状态。只有原投稿账号、作品 ID 与已公开父任务匹配后才进入发送队列。

防重有两层数据库约束：每个投稿只建一份作者评论；同一账号同一作品只能保留一个发送任务。worker 在 POST 前持久记录已经开始提交，固定请求只发一次，禁用网络重试和重定向。拿到完整评论 ID、原文、作者与一级评论回执后先落库，再读取创作中心评论列表核对。回读失败不重发；发送超时或回执不明进入「结果待核对」，重启保留该状态。后台最多自动执行 5 次只读回查（间隔约 2 分钟），也可点击「只读核对评论」；回查仅 GET 创作中心评论列表，不再次 POST。按本次时间范围、作者、一级评论和内容匹配；平台归一化空白时保留原始任务文本并记录该差异。只有明确未提交或平台明确拒绝时才提供手动重试。

页面同时显示自动公开核对是否运行、累计次数、最近检查时间与未确认原因。匿名详情没有 XHR 时尝试读取页面的 JSON 序列化内容，不执行脚本；仍要求精确作品、作者和明确公开可见状态。当前匿名详情不含 `reviewed` 时，还必须存在抖音域名的视频播放地址；明确私密、删除、禁止或审核中的状态均不能通过，不根据标题和管理页跳转推断成功。

评论接口及回执格式参考 [AiToEarn 固定提交的创作者适配](https://github.com/yikart/AiToEarn/blob/cb894a43b2d23cc1ad67d9e7729b1d86cf9360bd/project/aitoearn-electron/electron/plat/douyin/index.ts)。实际网页接口可能变化，离线测试不能替代当前账号的真实发送验收。置顶限制以官方下线公告为准。

## 三平台并行接入（2026-10-25）

原路线明确包含 B 站、抖音、快手。本轮在快手之外扩展小红书和微信视频号，由三个独立适配器接入相同的账号、发布包、持久队列与回执流程。平台管理与文稿发布页现均提供五个平台；每个平台仍只连接一个当前账号，历史账号记录保留。

| 新平台 | 账号标识来源 | 投稿回执 | 公开确认与后续能力 |
| --- | --- | --- | --- |
| 快手 | 官方网页 `userInfoQuery` 的 userId；创作中心专用登录态则读取真实签名 `home/infoV2` 响应的 userId/userName | 仅识别最终 submit 响应中的可靠作品 ID；上传分片 ID 和 publishId 不当作作品 | 可按准确作品 ID 检查账号归属；尚不能自动证明公开 |

三者均已实现扫码连接、验证/断开、独立发布包、显式手动投稿、队列、取消和安全重试路径。代码可执行不代表真实平台链路已验收：本轮未连接新账号、未执行真实上传，首评、置顶和数据采集均未开放。用户在创作中心确认后可手动补录准确平台、账号、版本及链接，记录继续标注“手动记录 · 未自动核验”。

### 共用执行约束

- 新平台注册于 `core/social/registry.py`，网页响应解析、身份核对和发布包限制留在独立适配器。接口由 `web/routes/social_publishing.py` 提供，后台按平台独立推进，每个平台独立锁和 `queue.db`，不互相阻塞。
- 凭证只保存在平台目录下，以稳定账号标识的 SHA-256 命名目录；目录 0700、文件 0600。接口只返回账号标识、昵称和任务元数据。截图只取实际二维码，不导出网页、cookie 或完整响应。
- 换二维码取消旧登录任务；旧 worker 发现取消后不保存或采用旧账号。普通用户 Chrome 不受控制，连接使用专属 Chromium。
- 快手登录表单在 DOMContentLoaded 后延迟挂载，连接须等待表单和扫码切换控件。普通网站与创作中心登录态分别处理，创作中心身份响应通过独立页面实际发出的请求取得，不将 token 搬到另一域、不根据 cookie 存在就确认登录；核对页在成功/失败后关闭。
- 复用固定 SAU 提交 `3847fff01f5434a8a32829833163cd6723cabc59`，运行前再次核验各平台源码 SHA-256。上游重复发布点击循环改为单次点击，禁用上游未经保护的账号探测和诊断日志。
- 最终发布 POST 仅放行一次；提交开始、调用开始、作品 ID 和不确定结果持久化。禁用请求重试、重定向及 Service Worker。worker 重入先读数据库，已开始提交且结果不确定时不再次调用上传组件。超时或异常无可靠回执进入 UNKNOWN。
- 无自动公开证据不自动回写“已发布”。新三个平台不启动自动公开轮询；不会将管理页跳转、标题相同或成功退出当作已公开。未知结果不开放重投。

### 接口与页面

- `GET /api/platforms/catalog`：只读的平台与能力目录。
- `/api/platforms/social/{platform}`：账号、候选与任务概览；`login`、`login/renew`、`verify`、`account` 管理连接；`preview/{render_id}`、`uploads` 和任务操作管理发布包与回执。
