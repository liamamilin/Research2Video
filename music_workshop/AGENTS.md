## 产品边界

- 独立子项目，核心流程是创意挖掘 → 歌曲创作 → MV 制作。
- 由用户或助手按作品主动发起；不加入周期任务，不绑定研究 Job。
- 题材自由，允许生活、职场、情绪、故事、知识等；不限制为 AI 吐槽。
- 优先打磨具体场景、人物视角、副歌钩子与视觉表达，目标是作品观看与传播表现。
- 当前为独立本地工作台，未来再讨论与剪映的衔接。不要把本项目 JSON 宣称为剪映草稿。
- 不自动接入、修改或启动研映与 AutoVideo 的生产任务；后续通过明确的适配器复用能力。

## 开发

- 在此目录运行 `python3 run.py`，默认地址 `http://127.0.0.1:8022`。
- `app/` 为 FastAPI、模型和 SQLite 存储，`web/` 为无构建依赖的界面，`tests/` 为后端测试。
- 运行 `python3 -m pytest tests -q`、`node --check web/app.js`，提交前从仓库根目录运行 `git diff --check`。
- 运行数据、音视频、截图与导出保存在忽略的 `data/` 或 `artifacts/`，保留用户作品与尝试。
- API 与界面如实区分已实现、外部生成、待接入；不要用本地模板冒充模型创作，不显示虚构的生成进度。
- 保持用户已认可的歌词和歌曲版本；演唱确认由实际试听结果记录，时间轴不能按字数均分后宣称精确对齐。
