# 音乐创作工坊 · Music Workshop

一个按作品主动推进的独立子项目：**创意挖掘 → 歌曲创作 → MV 制作**。

当前状态：**已归档，暂停推进（2026-11-10）**。保留 v0.1 创作工作台、创作案例和本地作品数据，等待用户确认后续方向。刚初始化的 `music-video-studio` skill 已取消并删除，未完成、未安装。

归档记录、已完成验证与待确认事项见 [归档交接](docs/ARCHIVE.md)。归档采用原目录保留方式，不移动或删除代码与作品；以下运行说明供后续恢复使用。

题材自由，不绑定研究矩阵与周期任务。未来是否继续工作台、改用 skill、接入 Mureka API 或衔接剪映，均待用户确认；当前导出是本项目 JSON，不是剪映草稿。

## 本地运行

在本目录执行：

```sh
python3 -m pip install -r requirements.txt
python3 run.py
```

打开 http://127.0.0.1:8022 。这是独立服务，与研映、AutoVideo 使用不同的端口和数据目录。

首次打开可点击「载入蓝按钮创作案例」。案例保存已确认歌词、Mureka 两个版本及用户选择的 69 秒版；不把原先不满意的 Gemini 音频当作新歌曲，也不捏造歌词时间码。

## 当前可用

- 新建、搜索、保存创意卡：原始灵感、具体故事、受众、人物视角、情绪、副歌钩子、画面与结尾。
- 按创意生成可复制的**挖掘简报**，交给模型或助手发展不同方向。这是简报整理，不是模型生成。
- 保存歌词和音乐方向；登记外部歌曲版本、时长、链接与试听反馈；采用一个版本。
- 为具体歌曲版本建立、编辑 MV 画面草案。
- 导出和重新导入版本化项目 JSON；导入形成独立作品。
- SQLite 持久化、历史修订保留、并发修改冲突提示。

## 目录

```text
app/        数据模型、存储、接口
web/        无构建依赖的本地工作台
examples/   可导入的创作案例
docs/       产品边界与后续路线
tests/      持久化、版本关联、导入导出测试
data/       本地 SQLite（不提交）
artifacts/  开发截图、检查记录（不提交）
```

可通过 `MUSIC_WORKSHOP_DATA_DIR` 指定独立数据目录。不会读取其他子项目的数据库、凭据或任务配置。

## 验证

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m pytest tests -q
node --check web/app.js
```

API 文档位于 `/docs`。基础接口为 `GET/POST /api/projects`、`GET/PUT /api/projects/{id}`、`GET /api/projects/{id}/prompt`、`GET /api/projects/{id}/export`、`POST /api/import`。

服务默认只绑定 `127.0.0.1`，无登录系统；用于个人本地创作，不作为公开网络服务。
