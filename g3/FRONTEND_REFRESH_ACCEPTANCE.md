# 前端工作台优化验收

2026-10-15。目标：让已完成的制作能力呈现为连贯、清楚、可持续使用的本地产品。

## 交付

- 统一字体、控件、间距和绿白配色；正文由 11px 调整为 14px，主操作与说明建立层级。移出日常界面的 G3、worker、SQLite 等工程标签，保留制作详情与文件入口。
- 创作台采用素材区与成片设置区，默认自动形式，可手动选择；声音、时长和倍速按需展开。首次输入为空，示例由用户主动载入；正文、标题、文档关联、声音、时长、倍速及形式在当前浏览器恢复。创作偏好沿用原有保存机制。
- 完成页以播放器配合画面、讲稿、声音、版本四个标签页。未提交的场景编辑在标签切换时保留；切换场景会提示未提交修改。场景缩略图横向浏览，并提供场景下拉定位；章节及技术文件默认折叠。播放器封面使用任务已验证的真实场景缩略图。
- 作品库接入服务端分页、标题/编号搜索及状态筛选；统计覆盖全部任务。待补充素材与执行失败分开展示，历史已完成修订不再显示仍在处理中。
- 保留历史知识卡片与 Draw Things 背景修订入口；保持原有生成和修订请求语义。

## 资源与实现选择

检查了已安装技能，并使用 plugin-management 检索 Figma、MagicPath 等设计插件。当前没有需要导入的外部设计稿，本轮沿用 React 与 CSS；参考 [shadcn/ui 官方 Blocks](https://ui.shadcn.com/blocks) 与[标签页组件](https://ui.shadcn.com/docs/components/tabs)的界面组织方式，自行实现现有应用。没有复制付费模板或新增前端运行依赖。
