# 音乐素材、背景配乐与混音

2026-10-23 第三阶段。音乐模块与视频形式、包装库并列，由制作配方组合；不修改冻结的 Video IR v0.2。

## 使用入口

- **创作资源库 → 音乐形式**：试听轻柔和声铺底（MF08）、渐进层叠音景（MF09）、轻节奏循环（MF12），点击“用作背景配乐”带入当前创作。保留原有 14 类音乐参考与来源说明。
- **新建视频 → 背景配乐**：开启配乐，选择素材或导入 WAV／MP3／FLAC／OGG。支持相对音量、淡入淡出、旁白时自动压低、循环。设置随浏览器草稿保存。
- **已完成作品 → 声音 → 修改背景配乐**：更换或关闭配乐生成独立版本，复用原画面、旁白、字幕和包装，不调用内容模型、不重新配音或渲染画面。

AI 快讯、操作教程、原理科普升级为 v3 配方，分别推荐渐进音景、轻柔铺底、轻柔铺底；默认关闭配乐，用户可显式开启。旧配方快照、旧任务和原有包装提示音保留。声音／倍速、素材／讲稿等修订继承冻结音乐；显式关闭优先。

本轮三个参考素材是用户提供目录中的原创程序合成示例，来源和原始 SHA-256 随资产保留。独立 AI 音乐生成尚未接入。

## API

1. `GET /api/music-assets` 返回素材与可用状态。
2. multipart `POST /api/music-assets`，字段 `file`，返回 UUID 与 `preview_url`；单文件最大 32 MiB、1 秒至 10 分钟。音频在本机解码并保存为 48 kHz 双声道 PCM16。
3. `GET /api/music-assets/{id}/preview` 提供 WAV 试听与 Range 响应。
4. `POST /api/jobs` 可增加：

```json
{"background_music":{"enabled":true,"asset_id":"ambient_pad","level_db":-18,"ducking":true,"loop":true,"fade_seconds":1.2}}
```

`asset_id` 接受注册素材 ID 或导入 UUID，不接受路径／URL。`level_db` 范围 −30 至 −12，表示配乐相对正文活跃旁白 RMS 的目标差；默认 −18。默认旁白期间进一步降低约 6 dB，攻击 30 ms、释放 300 ms。淡入淡出 0.1–3 秒，默认 1.2 秒；默认循环，重复处交叉淡化 0.25 秒。此处不是 LUFS 标准化或人工听审评分。

5. `POST /api/jobs/{id}/music-revisions`，请求体同上，返回独立子任务。`{"background_music":{"enabled":false}}` 从保留的未混音视频恢复原声音，结果与该原视频字节相同。

未提供音乐字段的历史请求保持原行为。新建任务冻结配置、音乐身份与哈希到 `input/input.json`、`input/music/asset.wav`，关联制作配方与制作计划。重试使用该文件；派生版本优先复制父任务冻结文件，同一素材的全局缓存不可用时仍可继承。

## 执行与验收

原正文质量检查、包装与提示音验收保持原标准。之后独立 `AUDIO_MIX` 阶段对正文时间段加音乐；片头、来源卡、片尾的配乐分轨为零，原包装音轨保留在参考原片中。最长 20 ms 一块流式处理，混音整体峰值目标不超过 0.90；必要时给整条混音留出余量。视频流直接复制，最终 AAC 为 48 kHz 双声道。

最终成片必须通过完整音视频解码、帧数／时长校验、编码视频流哈希不变、混音参考相关性 ≥0.98、扣除保存配乐后旁白相关性 ≥0.98、旁白活跃段能量比音乐高 ≥10 dB，以及解码峰值低于 1。失败不发布为已完成。保留纯旁白原检查，不能用放宽原音轨比较来通过混音。

主要制品：

| 文件 | 含义 |
| --- | --- |
| `video.mp4` | 最终混音成片；关闭配乐修订则为恢复原片 |
| `unmixed.mp4` | 本次混音前的原成片，含原包装 |
| `content.mp4` | 有包装时保留的正文原片 |
| `music-bed.wav` | 实际加入的配乐分轨，含淡化／压低／余量调整 |
| `mixed-audio.wav` | 编码前参考混音 |
| `music-mix.json`、`mix-qa.json` | 冻结选择、来源、增益、范围、哈希及 QA |

关闭配乐时不生成两个 WAV 分轨。仅换音乐始终从未混音原片开始，防止将上一版音乐再次叠加。纯音乐制作、歌曲生成、节拍匹配剪辑与自由多轨编辑留待后续。

真实样片、失败修复与验证边界见 [第三阶段验收](acceptance/music-mix-20261023/README.md)。
