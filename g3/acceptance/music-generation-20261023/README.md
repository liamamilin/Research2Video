## 边界

本阶段接入 10–30 秒无词背景音乐；真实新推理覆盖氛围 24 秒、电子 30 秒。钢琴预设与请求校验已接入，尚未新增其独立实片听审。纯歌曲、人声、歌词精确控制和多轨音乐编辑继续保留为后续能力；不以器乐替代歌曲宣称完成。风格、完全无人声、音乐性与题材契合仍需试听反馈，技术 PASS 不替代主观验收。模型需现有参考磁盘／本机运行环境；已入库的资产可脱离模型目录使用。
