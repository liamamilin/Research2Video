- 31 个稳定形式 ID：17 视频、14 音乐；五类包装组件继续来自原目录。案例与可执行能力分开。
- `media-previews.json`：25 份既有媒体均核对目录哈希，通过真实 FileResponse Range 请求，返回 206／64 字节；外接盘缺失、越界及身份变化有失败测试。
- `compatibility-final.txt`：28 项通过，包含新增功能的 22 项案例及工作区同期加入的提交去重、命令恢复检查。覆盖三配方的素材／定稿讲稿入口、显式覆盖、旧包装 API、依赖缺失、非法配方、冻结版本、重试／修订、worker 有效路由及篡改阻断。有效 worker 测试截停在子进程启动前，不冒充真实生成。
- 前端 vendored esbuild 构建通过；TypeScript 源码检查通过，使用现有类型目录、`--types react --skipLibCheck`，不检查 vendored 类型声明内部冲突。
- `browser-checks.json`：实际浏览器验证配方切换、原文与标题保留、手动覆盖、刷新恢复、隔离任务提交、视频及音频播放器、包装入口与桌面／窄屏布局。截图保存在同目录。

- `service-update.json`：确认正式 8011 实例无运行／排队任务，核实 PID、命令、工作目录及监听端口后正常 SIGTERM，使用已有 launcher 启动新服务。31 类／3 配方接口与主 worker 正常；正式制作记录重启前后均为 153 条。正式页面截图 `live-resource-library.png`。
- `git diff --check` 通过。用户原有未提交改动保留；同期去重和命令恢复改动未覆盖。
