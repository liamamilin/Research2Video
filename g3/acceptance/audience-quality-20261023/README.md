# 观众文案与事实限定打磨

范围：同一篇《续航手机最抢眼，五件新品变化速览》，修复文稿、审校和快速卡片提炼中的内部备注、缺乏指向的句子和限定误判。不扩展音乐、风格或生产入口。

## 处理

- 写稿、改稿及两套审校共享观众文案规则。研究摘要没有收录信息不等于原来源没有；不把资料缺口搬进旁白，也不凭缺项编出否定事实。明确的内部备注进入修复流程；修复后仍有核心问题时自动出片暂停。
- 本篇逐页核对五个发布者原网页，修正耳机链接 `hands-on` / `handson` 差异、并购完成状态及摘要缺项造成的错误印象。原报告、v1–v4 和旧核实标记保留，新稿为 v5。
- 测试场景、媒体体验和未来计划直接放在相关主句里，去掉重复的防御性说明。来源核验快照按现有来源清单格式提供标题、发布日期、性质及网址；主要来源卡恢复，完整五个来源留在报告和简介。
- 新卡片使用带原文证据的短重点和逐项限定标签；取消自动复制整段“口径与限制”。不再因“能不能”误判限制，不将否定或推测摘成肯定，不把“肯定”这样的评价动词当来源标签，不让“则……”等片段丢掉主语。
- 历史卡片的声音/速度修订保留旧限定布局，新稿和新提炼页使用新布局，避免修订时丢失旧事实边界。
