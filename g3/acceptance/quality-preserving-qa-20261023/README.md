# 同质量扫描与预览优化验收

2026-10-23。原稿《续航手机最抢眼，五件新品变化速览》定稿 v1，通过研究系统原有「快速卡片出片」入口提交，完成 AutoVideo 生成及研究端回传。

## 本轮实现

- 打包成片的帧计数、视频逐帧格式和音频逐帧格式改用一次 ffprobe 扫描。保留独立 ffmpeg `-xerror` 全量解码，以及时长、编码、声道、旁白偏移相关性、响度和峰值检查；扫描帧数必须与解码计数一致。
- 包装预览由逐张启动 ffmpeg 改成一次抽取全部目标帧。目标帧去重后仍按原顺序和标签布局；抽取数量不足会报 `PACKAGE_PREVIEW_MISMATCH`，独立目录防止旧图片误通过。
- 配音、编解码器参数、分辨率、帧率、内容、片头片尾、来源卡、角标、提示音、字幕和验收阈值均沿用。变更位于共同包装阶段，适用于现有各形式；本轮实际性能样本为快速卡片。
