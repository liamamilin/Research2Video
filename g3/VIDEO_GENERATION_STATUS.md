# AutoVideo 视频生成现状

整理日期：2026-10-23，Asia/Shanghai。依据当前代码、发布记录与已保存的真实媒体验收证据。

本轮仅核对和整理，没有启动生成、改动产品功能或重新运行完整回归。音乐继续暂缓；视频和音乐的后续批次均不推进。现有入口、素材、任务、成片、失败尝试和版本保留。

## 1. 当前已经能完成什么

当前核心链路是：文稿／文档／上游定稿，加上可选的已有图片 → 制作配方与形式选择 → 讲稿组织或逐字采用 → 本机配音 → 分镜／排版 → 渲染 → 包装 → 媒体验收 → 作品预览与下载。

| 环节 | 已完成能力 | 使用边界 |
| --- | --- | --- |
| 输入 | 粘贴素材，TXT、Markdown、DOCX、文字型 PDF；上游通过 API 提交分章定稿 | 文档提取后可编辑；扫描件不支持 OCR；文档中的图片不会自动成为配图素材 |
| 内容组织 | 素材整理、重复和粘贴噪声记录、关键冲突提示、完整材料自动分章 | 素材模式会组织／改写讲稿；要求逐字保留时使用定稿模式；不自动核实外部事实 |
| 定稿出片 | 保留章节和原文，逐字配音及字幕校验，只安排画面 | 文字一致不等于读音正确，也不等于所有屏上概括都已达到最佳表达 |
| 题材配方 | AI 快讯、操作教程、原理科普三份 v5 配方 | 配方提供默认形式、偏好和包装；允许本次覆盖，不与形式一一绑定 |
| 创作资源库 | 视频／音乐分类、参考案例、可制作状态、配方和包装的统一入口 | 有案例可看不代表已有自动生成执行器 |
| 已有图片 | PNG／JPEG／WebP，1–12 张，顺序调整、说明及整体／细节／对比用途 | 图片复制到任务并校验哈希；不理解未标注的像素内容，不下载任意远程图片网址 |
| 本机配音 | Kokoro、Qwen3-TTS、VoxCPM2；可试听；包含普通话及预置北京／四川口音 | 当前本地声音目录将 14 个声音配置标为可用；不代表逐个音色、术语和长稿均已主观验收 |
| 导出速度 | 0.5／1／1.5／2 倍，声音、字幕、动画同步；可恢复正常速度 | 会生成独立成片，使用正常速度音频处理；不只是播放器倍速 |
| 包装 | 片头、片尾、角标、来源卡、提示音；通用默认、配方和本次设置继承 | 来源卡只使用提交的数据；没有来源时不编造；片头偏移同步到字幕和章节 |
| 修改版本 | 原稿／讲稿修改，换声音、调倍速；两种主形式可单幕文字编辑或 AI 重排；旧背景图修订保留 | 所有修改生成子版本；新形式没有全部开放单场景自由编辑；单幕修改仍可能重合成整片 |
| 工作台 | 草稿恢复，队列／日志／取消／重试，作品分页搜索，场景与章节跳转，文件下载及版本关系 | 仍是本地单机产品，不代表多用户生产平台 |
| 上游衔接 | 研究系统定稿出片、快速卡片、制作配方／矩阵显式覆盖；幂等提交、精确对账、断线后继续复制 | 下载复用须通过大小和 SHA 校验；传输恢复不等于任意生成阶段断点续跑 |
| 制作追溯 | 制作计划、配置来源、配方／组件版本、输入与图片哈希、实际执行器冻结 | 重试沿用旧快照；后续默认调整不自动改写历史作品 |

输出主体为 1920×1080、30 fps、H.264／AAC 横屏 MP4，另有字幕、章节、讲稿和 QA 文件。保留 10–90 秒指定时长和按内容时长两种路线；已有约 3.5 分钟快速卡片及约 8.9 分钟完整材料视频证据，不代表所有长度、题材都已逐一验证。

## 2. 目前可用的视频形式

新建页有八种具体形式，另提供“自动选择”。旧知识卡片与背景图路线继续保留在 API 和历史兼容能力中。

| 形式 | 适合的现有输入 | 已实现的表现与限制 |
| --- | --- | --- |
| 流程动态图解 | 有步骤、条件、分支、因果或系统流转的文稿 | 自动关系规划、ELKjs 布局、节点／连线随旁白展开；可单幕修订 |
| 简洁信息动效 | 观点、要点、并列事实、对比文稿 | 标题／概念／对比卡、大数字、受控条形图；可单幕修订 |
| 动态排版 | 以文字表达为主的文稿 | 按实测配音逐句展开、文字分组进入 |
| 图片轮播 | 文稿和有序图片 | 图片切换、轻微运镜、图文与配音；无图时的自动插画依赖本机 Draw Things |
| 聊天对话体 | 问答式或可组织为问答的文稿 | 气泡、提问与回复；保留显式角色标记，当前统一旁白，不是多角色配音 |
| 信息卡片 · 快速 | 素材或定稿，尤其已有分章定稿 | 受控抽取原文重点，主画面与短字幕分工；本机强制对齐字幕，原生合成，浅色风格 |
| 对象展示 | 文稿和对象的整体／细节／对比图片 | 主图、缩略栏、说明和旁白重点；不生成不存在的对象细节 |
| 动态拼贴 | 文稿和已有图片 | 同时最多三张图的多层版面、说明标签与旁白卡 |

“自动选择”目前只在流程动态图解与简洁信息动效之间判断。其他形式由配方或用户指定；基于图片数量和用途的推荐也需要明确点击应用，不会自动覆盖手动设置。

17 类参考目录的准确口径：

- 已接入 6 类：F04 对象展示、F08 动态排版、F10 信息图动画、F12 图片轮播、F13 动态拼贴、F16 聊天对话体。
- 部分接入 1 类：F09 图形动画，借助现有信息动效表达；没有完整专用图形动画模板。
- 其余 10 类仅保留分类和案例参考，没有自动制作路线。
- 快速信息卡片另以原生形式 AV01 登记；F10 又可以由两种执行方式实现，因此不能把“17 类目录”和“制作入口数量”直接相减。

三配方当前默认：AI 快讯用动态排版；操作教程用流程动态图解；原理科普用自动选择。已有图片时均可按需要切换对象展示、拼贴或轮播。背景配乐默认关闭。

## 3. 最近已修复或改善的事项

快速卡片此前发现的主画面大段重复旁白、半句独立分页、英文断词、浅色角标白字、无文字黑块误过字幕检查，已有对应实现与验收证据，不能继续全部列作未修复缺陷。

最新同稿样片由 31 张原文卡调整为 12 张重点卡，字幕独立拆成 53 条，成片 212.9 秒；重点与原文引用、事实限定、完整短字幕覆盖均通过检查，85 个字幕／间隔取帧检查点通过。原始旁白 PCM 与旧版相同，最终成片解码后的音轨也与旧版相同。片头采用本期短标题，片尾改成观众可读文案。见[快速卡片质量证据](acceptance/card-quality-20261023/verification.json)。

任务可靠性方面已处理：提交响应丢失导致重复任务、恢复进程重复跟踪、下载失败重传大视频、掉盘时误建路径、日志半行遗漏、子命令超时丢失输出及监控异常遗留进程。见[提交与恢复验收](acceptance/video-hardening-20261023/README.md)。

性能方面已接入整章配音缓存、VoxCPM2 编译与参考编码复用、HTTP 连接复用、有限并发回传、合并媒体扫描和预览抽取。仍保留完整解码与音轨／字幕检查。性能数据按条件分别记录，不能将不同画面方案直接比较：

| 已保存的同稿实测 | 从研究端创建至完整回传 | 含义 |
| --- | --- | --- |
| 原快速版，全新配音 | 453 秒 | 原卡片方案的基线 |
| 配音与恢复优化后，全新配音 | 321 秒 | 同稿、同音色的实测，不是所有新文稿的承诺 |
| 配音缓存全部命中 | 90 秒 | 复用完整章节音频 |
| 同方案扫描／预览优化，缓存命中 | 77 秒 | 与上一行同质量比较；最终 MP4 逐字节相同 |
| 最新重点卡＋短字幕版，复用配音 | 166 秒 | 增加重点规划和强制对齐后的质量版本；不是上一行的等方案速度回退结论 |

最新重点卡版的耗时仍含约 87 秒画面重点规划；先前全新配音样本中配音与对齐约 223 秒。长稿耗时尚未消除。

## 4. 仍有的问题和限制

| 项目 | 当前未解决或未充分验证的部分 | 对使用的影响 |
| --- | --- | --- |
| 配音听感 | 技术词、英文、多音字、语调及长稿声音稳定性没有全面听审；字幕逐字一致不验证每个读音 | 重要文稿仍需试听，不能宣称机器配音已全面自然、准确 |
| 屏上重点与事实限定 | 标准信息动效部分忠实度检查是软校验，重试不足时可能保留警告；标题通顺程度仍依赖规划；快速卡片的抽取与约束改善不等于所有题材均稳定 | 数字、对象、条件、否定及结论关系仍需抽查；媒体 QA 不代替内容和观感验收 |
| 版式与观看质量 | 受控模板数量有限；快速卡片只有一种浅色风格；高密度、长标题和不同题材缺少广泛样本 | 真实样片通过不代表所有稿件都无拥挤、层级或节奏问题 |
| 图片与讲稿对应 | 按顺序、显式编号及提交者标注组织；没有图片语义识别，也不会自动搜图或核实配图内容 | 上游／用户仍需提供正确图片、顺序和说明 |
| 自动插画 | 早期有 Draw Things 场景图证据，但图片轮播阶段验收时本机未连接，缺少该轮自动插画端到端证据；本轮未重新探测连接 | 现阶段优先使用已有图片，不能把自动配图描述成当前稳定可用的默认路线 |
| 来源呈现 | 当前请求最多 3 条来源；主要来源卡没有与每章／每项事实逐一关联 | 有逐章待核实提示，但它不等于逐章完整来源追溯；多来源长稿展示仍受限 |
| 流程图 ID 合同 | 规划和节点／边 ID 允许 48 字符，但组件布局里的 ID 仍只允许 24 字符，旧验收曾记录因此编译失败 | 模型给出较长 ID 时仍有合同冲突风险；本轮只核对，未修改冻结 schema 或复现生成 |
| 修改粒度 | 新形式未开放全部单幕自由编辑，快速卡片以讲稿／声音修订为主；部分局部修改仍需重合成全片 | 没有自由时间线、多轨编辑，也不保证只重算受影响视频片段 |
| 成功率与耗时 | 仍可能因模型结构、引文、容量或调用额度失败；有纠错／重试但无多题材稳定成功率统计；没有完整通用阶段断点恢复 | 不能承诺每份稿件一次成功，也不能用缓存成绩承诺全新长稿耗时 |
| 批量能力 | 20 条全新稿件吞吐、资源峰值、恢复与并发尚未完整压测；多用户可靠性未验证 | 当前定位仍为本地单机工作流 |
| 输入和输出边界 | 不支持扫描件 OCR、复杂文档可靠版面阅读、文档图片自动提取到配图、任意网页／音视频解析；无自由横竖屏切换 | 上游先整理为正文及已取得图片更合适 |
| 工程验收基线 | 冻结文档包清单仍与工作区不一致，设计快照检查在 AGENTS.md 失败；全目录清单测试会把运行数据／依赖纳入比较 | 是尚未收口的文档／发布验收问题；不能把最新全量测试说成全绿 |

最近保存的回归结果为 **650 通过、1 跳过，另 1 项文档清单测试失败**，研究端相关回归 151 通过。旧图片批次记录的两项快速卡片夹具失败已不再出现在这份更新结果中，保留为历史记录。依据是[最新回归原始日志](acceptance/card-quality-20261023/regression-final.txt)，本轮未重新执行测试。

## 5. 明确暂不推进的范围

- 音乐：停止继续生成、混音调参和试听推进；已有问题见[背景配乐反馈](acceptance/music-curation-20261023/LISTENING_FEEDBACK.md)。现有能力与素材保留。
- 其余视频批次：镜头叙事、人物口播、对话表演、角色动画、动态插画、定格风、抽象视觉、分镜漫画、界面演示和镜头混剪，均不启动。
- 录屏、拍摄、出镜和连续故事等高素材成本路线不扩展。
- 更多视觉风格、多角色配音、自由时间线／多轨、竖屏及批量调度不在本次整理范围。
- 中文歌曲不接入。

本次完成的是现状与问题归档，不自动把上述问题转成新的实施批次。
