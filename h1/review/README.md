# H1 评测材料

请只使用 `BLIND_REVIEW_PACKAGE_v3.json` 中列出的 12 个编码样片，并按 `BLIND_REVIEW_FORM.md` 单独填写六组配对的五维评分、偏好和观察。不要向评议者提供任何 `H1_REVIEW_KEY*.json` 文件，也不要在评分锁定前揭示 B/C 路线。

编码只隐藏了路线标签；AI 背景本身可能使处理方式可见，所以这是盲编码评测，不是严格双盲。两名独立评议者各自完成后，再用 `H1_REVIEW_KEY_v3.json` 解码并汇总。

历史包 `BLIND_REVIEW_PACKAGE.json`、`BLIND_REVIEW_PACKAGE_v2.json` 及对应素材为早期 QA 版本，不用于正式评分。联系表 `contact-sheet-blind-v3.jpg` 仅作快速浏览，评分请播放完整片段。
