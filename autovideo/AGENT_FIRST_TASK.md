# 编码 Agent 首轮任务记录（G0）

本文件保留 AutoVideo 初始化时的 G0 首轮任务文本，用于追溯当时的范围与硬约束。该任务已经执行并形成 `G0_REPORT.md`；G1–G4 后续验收和当前状态见 `RELEASE_STATUS.md`。新任务应从当前用户指示开始，不要把本历史首轮任务误作尚未完成的待办。

**本轮只执行 G0 技术验证，禁止未经用户授权继续 G1。**

## 目标

1. 核查本机 Node、Python、Remotion、FFmpeg/ffprobe 和实际 TTS provider 的可用性、版本与授权条件。
2. 用中文知识示例生成一段**真实** 10–20 秒视频，画面包含至少一个随旁白发生可观察变化的程序化动画，包含真实中文 TTS、与音频时间对齐的字幕。
3. 渲染可播放、有音轨的 MP4，使用 ffprobe/实际解码验证，保存关键帧、真实终端日志和依赖版本。不得用截图、Mock、静音视频代替真实验收。
4. 输出 `G0_REPORT.md`：状态 PASS/PARTIAL/FAIL、实测环境、执行命令、产物路径、音频/视频检查结果、画面和声音问题、费用/授权与风险、下一阶段建议。
5. 测试/修改必须在本项目范围内进行，不覆盖已有代码、未提交工作、系统配置和其他项目。提交 Git commit；如果无法提交，说明准确原因。

## 硬约束

- 不需要实现完整 Web UI 或 IR v0.2 编译器；G0 仅证明真实音画链路。
- 用户文本、API 响应与 LLM 输出不能作为本机任意 shell 或 JS/TS 执行。
- 密钥只能存在后端配置/环境变量，不得写入日志和 Git。
- 如缺少真实 TTS 授权/密钥或环境无法渲染：明确写 PARTIAL/FAIL 并报告阻断；不可使用 Mock 伪造 PASS。
- 完成并提交报告后停止，等待用户确认 G1。
