# 14｜V0.2 设计审查与未完成项

**审查日期：2026-10-13**  
**本次范围：只修改文档和 Schema；未开始项目代码开发，也未生成真实视频。**

## 这次修复了什么

1. **静态页面偏向**：引入 `visual_intent`（解释目的）+ `beats`（状态变化），不再把镜头简单等价为一张图。
2. **动画不可编排**：每个 Beat 可以以旁白段真实时间为锚点，具体动作由注册组件安全执行。
3. **LLM 伪时间戳**：区分 StoryboardPlan 和可执行 IR；真实音频与 aligner 生成时间证据，编译器负责计算帧。
4. **动作越权**：组件 props Schema + Action/Target 注册表限定模型能够表达什么。
5. **测试只验证生成成功**：加入 Beat 前后状态、布局与中文字幕、时间线交叉引用、非法动作的测试矩阵。
6. **跨语言毫秒舍入**：明确 half-up 整数帧算法 `floor((ms * fps + 500)/1000)`，避免 Python 与 JS 对 `.5` 的舍入分歧。

## 推荐推进顺序

1. 暂不扩大产品范围，执行 G0 真实 TTS + Remotion 样片。
2. 用 G0 观察到的真实问题微调声音与字幕 tokens，不要直接变更 v0.2 结构而不记录版本。
3. G1 优先证明 `flow_diagram` 的 3 个语义动作而不是铺六个静态模板；再完成全套组件。
4. G2 使用真实 LLM 生成 `visual_intent + beats`，人工只参与**研发阶段样片评议**，不介入每条正常视频生产。

## 关于自动生成声音的产品边界

长期目标是声音和画面都无需人工创作；**V0.1** 的旁白由 TTS 真实自动生成，音乐/音效可以取自已授权素材，属于对首版交付范围的工程收敛，而不代表最终产品永远依赖预制音效。
