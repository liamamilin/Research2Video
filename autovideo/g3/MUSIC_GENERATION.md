# AI 音乐生成与资源入库

第四阶段（2026-10-23）：基于已安装的 [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) 本机模型，先接入用于视频配乐的无词音乐。音乐先完成独立制作并入库，再供多个视频复用；沿用 [现有背景配乐与混音](MUSIC_MIX.md)。

## 使用

创作资源库的“音乐形式”页新增“AI 音乐生成”。填写名称、风格、时长和可选描述／种子，点击“生成音乐并入库”。支持轻柔氛围、温暖钢琴、轻快电子三种方向，时长 10–30 秒，默认 24 秒。任务显示校验模型、加载、生成、检查和入库进度；可以离开页面，回到资源库继续查看，也可取消。

成功后，结果出现在同一音乐素材列表，标注“AI 生成”，可试听并点击“用作背景配乐”。制作配方卡片上的“搭配已生成的音乐”可选择结果，再应用 AI 快讯、操作教程或原理科普配方。本次选择进入创作草稿和任务的配方／制作计划快照；其他任务和配方默认保持原设置。

新建视频、已完成作品的“声音 → 修改背景配乐”内也可展开“生成新的 AI 配乐”。完成后点击“使用这首音乐”，再创建视频或配乐修订版。入库后的生成音乐与导入音乐共享选择、冻结、混音、下载、重试及修订继承机制。

这里的风格与无词要求是模型的生成条件；生成后建议实际试听。技术通过不代替音乐性、题材匹配或完全无人声的人工听审。有词歌曲、演唱与歌词控制仍按资源库各形式的状态标注。

## 本机运行与保留数据

默认模型位置为创作参考目录的 `music-pilot/`，可由环境变量 `AUTOVIDEO_MUSIC_MODEL_ROOT` 配置。复用已有 Python 3.11 环境、Turbo DiT、VAE 与 Qwen3-Embedding 文本编码器，模型及代码版本由 `g2/music_engine/runtime-manifest.json` 固定；每个任务完整校验所用权重与源码，不启动旧试验脚本、不改动旧额度台账。旧工程搬移后失效的链接不予改写，AutoVideo 在各音乐任务目录下创建自己的权重视图。

推理使用 PyTorch／MPS，单批次、8 步、不启用音乐语言模型、隐式下载或网络连接。可用内存不足 12 GB 时明确失败；低于 24 GB 时启用模型 CPU 卸载以控制占用。音乐与视频共用现有单 worker 依次执行，视频队列优先，避免 AutoVideo 内部同时进行大型音乐推理和配音／渲染。其他应用的资源占用不由 AutoVideo 控制。

任务数据库为忽略目录中的 `g3/data/music-jobs.sqlite3`；每条任务保存 `request.json`、运行日志、模型输出和 `result.json` 到 `g3/data/music-jobs/{id}/`。生成失败、取消和中断均保留原输出；重新生成创建新任务并保留原种子与父任务关系，不自动重试推理。成功音频经完整解码、时长（误差不超过 0.5 秒）、非静音、大小与 SHA-256 校验，规范化后保存至原音乐素材目录。取消决定与开始入库通过同一事务串行；进入最终校验入库后取消按钮停用，等待完成，避免取消与保存同时发生。

生成结果保存模型／权重版本、种子、提示、实测耗时、原始输出哈希及生成任务身份。配乐快照及混音报告中的 `music_generated`、`background_music_generated` 会反映实际资产来源。关闭配乐仍不添加音乐；旧任务不自动生成或替换音乐。

模型磁盘不可用时，生成入口显示缺失原因，已入库的本机音乐与现有视频继续可用。生成不依赖视频内容模型的 API 密钥。

## API

| 请求 | 用途 |
| --- | --- |
| `GET /api/music-generation/status` | 本机文件预检、风格与时长范围；不加载模型 |
| `POST /api/music-jobs` | 提交一条生成任务，返回 202 |
| `GET /api/music-jobs?limit=20` | 最近音乐任务（最多 50） |
| `GET /api/music-jobs/{id}` | 状态、设置、失败原因和入库 `asset_id` |
| `POST /api/music-jobs/{id}/cancel` | 取消排队或运行中的任务 |
| `POST /api/music-jobs/{id}/retry` | 失败／取消后，按原设置创建独立新任务 |

```json
{
  "name": "科普轻柔氛围",
  "style": "ambient",
  "description": "Soft background, space for spoken narration.",
  "duration_seconds": 24,
  "seed": 42610,
  "idempotency_key": "my-music-request-001"
}
```

`style` 为 `ambient`／`piano`／`electronic`；描述最大 220 字符。可省略种子，由服务生成并冻结；种子范围 0–2147483647。可选 `bpm` 为 50–160，省略采用风格建议。同一幂等标识和请求返回同一任务，设置不同返回 409，避免未知提交结果导致重复推理。请求不接受路径、远程网址、歌词、自由执行命令或客户端生成结果。

`COMPLETED` 时使用返回的 `asset_id`，通过原 `background_music` 字段创建视频或配乐修订；也可与 `production_recipe` 一起提交。上游推理接口依据 [官方 Inference API](https://ace-step.github.io/ACE-Step-1.5/en/INFERENCE)，实际运行固定在本机已验证版本。

本轮实片、真实音乐、运行日志与边界见 [第四阶段验收](acceptance/music-generation-20261023/README.md)。
