# 创作资源库与制作配方 · 第一阶段

第二阶段已接入 F08 动态排版、F12 图片轮播、F16 聊天对话体，配方升级为 v2，详见 [当前形式说明](CREATIVE_FORMS.md)。本文其余内容保留第一阶段的架构与验收背景。

AutoVideo 是统一创作入口。视频形式库、音乐形式库和既有包装库并列，制作配方引用它们，给出题材建议和当前可执行的制作设置。

## 使用入口

侧栏“创作资源库”（`/#resources`）提供三份配方、17 种视频形式、14 种音乐形式和五类包装组件。新建视频页可直接选择配方，再调整表现形式、创作偏好、包装、声音和时长。选择配方不修改标题、正文、文档关联或声音；“自定义设置”保留当前设置并解除配方关联。浏览器草稿保存选择和调整后的设置。

| 配方 ID | 名称 | 当前执行方式 | 包装默认 |
| --- | --- | --- | --- |
| ai_news | AI 快讯 | 简洁信息动效 | 1 秒片头、1.5 秒片尾、角标、来源卡（有来源时）、提示音 |
| how_to | 操作教程 | 流程动态图解 | 无片头、1.5 秒片尾、角标、来源卡（有来源时）、无提示音 |
| science_explainer | 原理科普 | 按材料选择信息动效／流程图 | 1.5 秒片头、2 秒片尾、角标、来源卡（有来源时）、无提示音 |

三份配方默认按完整内容决定时长，正文不添加背景音乐。音乐类型推荐保存在配方中，音乐生成和正文配乐属于后续阶段。F10 对应现有图表／流程能力；F08/F09 只标记部分表达可用，其余形式不开放自动制作。界面演示等推荐方向不会被冒充为当前已实现的生产路线。

## API 与优先级

`GET /api/creative-resources` 返回版本化目录、配方、执行能力和包装目录。原 `GET /api/packaging` 保留。

通过原 `POST /api/jobs` 提交 `production_recipe: "ai_news"`、`"how_to"` 或 `"science_explainer"`，连同原素材或定稿讲稿字段。例如可附 `packaging: {sound: {enabled: false}}` 覆盖快讯提示音。

配置顺序为配方默认 → 本次显式设置 → 既有类型及依赖校验。嵌套偏好和包装字段逐项合并，显式空字符串、false 等不会被默认覆盖。配方适用于定稿讲稿与文档输入。未知配方、未知字段和未支持的 `video_form` 在创建任务前拒绝；缺少流程图依赖时返回原预检错误。

未提交配方的旧调用方保持原默认形式、时长与通用包装。旧 `package` 格式仍可用，不与配方默认 `packaging` 冲突。既有 `packaging.recipe` 继续作为包装来源标签，不承担新增的制作配方解析。

## 版本与产物

定义位于 `g2/creative_library/catalog.json`。任务保存 `production_recipe_resolved`，含配方定义、目录哈希、实际请求设置、音乐执行状态、包装快照哈希和自身完整性哈希。任务列表／详情返回该字段；已完成任务提供 `production-recipe.json` 下载。

重试沿用原任务快照。内容、画面、声音及背景修订继承冻结定义和包装快照，重新记录本次有效设置；修改目录默认不影响旧作品。`auto` 是请求时的选型策略，实际选型由既有 `input-brief.json`／`resolved_video_form` 记录。worker 在生成前检查快照，缺失或被改动时以 `PRODUCTION_RECIPE_INVALID` 停止。

SQLite 增量增加可空的 `production_recipe_json` 列，历史任务保持空值。原作品、attempt 和文件不迁移或覆盖。

## 案例与来源

31 个稳定 ID 与原分类来自外接工程恢复包；源版本、哈希保存在目录 provenance。题材标签与三个配方是可修改的推荐，不是形式的硬限制。

25 份已有案例只读引用，不复制模型或大批媒体。`GET /api/creative-resources/{form_id}/preview` 仅提供登记的固定媒体，访问时验证 SHA-256，支持播放器 Range 请求。默认案例根为 `/Volumes/个人资料/2026/视频生成工作流/AI创作`，可用 `AUTOVIDEO_CREATIVE_ASSET_ROOT` 配置。磁盘缺失不阻止浏览或现有制作；案例缺失、越界、链接逃逸或身份变化会拒绝预览。

媒体演示与制作能力分别标注；程序绘制、程序合成和历史模型案例保留来源说明。播放器能加载不代表艺术验收或完整听审通过。

验收记录见 `acceptance/creative-resources-20261023/`。本阶段不改 renderer、Video IR 或模型提示，不新增推理调用。
