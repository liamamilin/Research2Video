# 自动数据画面与混合分镜 V1 / V2

2026-10-26：混合分镜已接入[统一对象图标与动作](VISUAL_LANGUAGE.md)，可以将流程图、概念和对比与既有截图、图表组合，并按旁白自动选择图标和少量短动作。

目标：把上游讲稿、数字和结论用视频展示好。画面编排直接消费这些输入，安排表现形式、出现顺序、重点和旁白节奏，不新增出处查询、事实审查或重新计算环节。

## 使用

研映的标准制作和矩阵自动批次共享 `video_render.create/process`，新任务默认发送 `visual_storytelling: true`，无需逐段选择图表。文学朗读沿用原呈现；快速卡片、聊天、图片轮播及显式指定的流程图继续使用原专用形式。

AutoVideo API 的直接调用者可在分章讲稿请求中加入：

```json
{
  "input_mode": "narration",
  "duration_mode": "content",
  "video_form": "information_motion",
  "visual_storytelling": true,
  "chapters": [{"title": "月度使用量", "paragraphs": ["一月12万次，二月18万次，三月16万次，四月30万次。四月达到最高点。"]}]
}
```

API 默认保留既有方式。已冻结的制作请求和历史视频不批量修改。按讲稿修订时继承选项，声音和倍速修订保留原画面。

## 已实现的画面

- 普通数字、价格变化、简单条形图继续使用已有可信组件。
- 趋势图：1–3个系列、2–8个时间点，折线跟随讲述展开，结尾强调相应时间点和上游结论。
- 多组比较：2–8个类别、最多3个系列，按讲述逐组出现，可突出整个系列。
- 同一条视频按段落混合页面截图、数字变化、图表和文字。图片来自已登记素材及段落映射；数据段落优先使用数字或图表，其余配图段落展示对应截图。
- 新编排中的价格变化将旧值、新值、幅度绑定到旁白中的对应数字，分别出现，不新增差额计算。
- 截图聚焦和图表段落共用字幕；包装继续使用现有片头、片尾和角标。

编排请求按章节合并，保留每个原始段落的分组，避免将上游的长段落拆成连续闪过的单句卡片。段落内出现位置优先采用模型选出的讲稿短语，定位到实测配音短语后按字数估计句内位置。

## 实现

- `g2/explanation.py`：段落画面选择、图片与图表组合、讲稿和画面修订。
- `g1/renderer/src/DataChart.tsx`：ECharts 6.1.0，只引入折线、条形、坐标系和SVG渲染。固定尺寸、固定坐标范围、固定边距；静态SVG分层缓存，设置 `animation: false`。
- Remotion仍为4.0.535。揭示、裁切、强调、字幕和镜头效果都由当前视频帧控制，不依赖网页时钟或CSS动画。
- 运行时使用 `presentation.preset: explanation` 和注册的 `data_chart`，保留冻结的MVP合同。仍只执行仓库里的受控组件。
- Node依赖更新在 `g0/remotion-package.json` / `g0/remotion-package-lock.json`；现有依赖目录安装 `echarts@6.1.0`，新环境沿用 `g0/README.md` 的锁文件安装方式。

## V2：二维关系与讲解重点

当上游同一个对象同时给出了两个数值维度，编排器可以自动使用 `scatter_chart`，例如成本与处理速度、单次价格与任务得分。

- 每张图2–10个对象，各自保留名称与x/y数值；两个坐标轴分别展示名称、单位和可选的方向提示。
- 随旁白逐个出现；当前对象带有圈选、坐标辅助线和指标卡。
- 可自动编排后续比较步骤：先比较A和D，再看B和C，最后突出B。每一步关联讲稿短语与1–3个对象，同一张图保持固定坐标。
- 数据点名称自动避让；小数刻度、分组颜色、相同位置、平坦范围和负数按同一组件展示。
- 讲稿中的短语即使跨过配音分句，也能定位其起点；展示结论、切换重点继续使用视频帧驱动。
- 沿用V1的入口与混合分镜，截图、数字变化、趋势、多组比较及散点可以出现在同一条视频里，用户无需另选模式。

新增受控组件为 `g1/renderer/src/ScatterChart.tsx`，使用现有ECharts 6.1.0和Remotion 4.0.535，没有升级依赖。画面修订可以调整轴名、对象名称和强调说明，声音／倍速修订继续保留数据和原画面计划。
