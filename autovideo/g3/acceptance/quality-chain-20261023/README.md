# 公共质量链路验收

2026-10-23。验证文稿、审校与快速卡片提炼为公共能力，手动/自动入口、旧稿缓存和独立 AutoVideo 输入不会绕过内部备注检查。完整覆盖说明见 Research 的 `spec/video-quality-coverage.md`。

## 实现与范围

- 写稿与审校沿用公共指导；9 份配方、16 个受众展开栏目、45 份生产配置均走同一处理层，当前 12 个矩阵没有稿件白名单。
- 旧版审校成功记录叠加当前本地检查；不改历史模型结果，不冒充事实复审。列表与看板同步显示口播问题。
- 手动定稿、手动出片、步骤重跑、助手和自动出片共用检查。自动矩阵仍执行事实审校门槛；手动事实决定沿用原功能，真实待核实原因和成片提示保留。
- 独立 AutoVideo 的原稿、素材、章节旁白、旁白修订及复用旧旁白的画面/音色/速度/背景修订都检查；原稿不能暗中改写，生成旁白的问题回到有限重试。
- 快速卡片的重点提炼、归属与条件标签、短句字幕适用于所有选择该形式的配方；其他形式保留自身结构与校验，没有改成卡片模板。
- 两个项目独立运行，各自提供公共边界检查，跨仓库合约回归核对规则一致。内部研究备注与化学/物理材料性质、官方标称、测试范围、有限体验相区别。
- 已生成视频下载失败后继续原下载，不重新生成；旧稿、旧片和失败尝试保留。

逐条取得原网页、修正耳机来源链接和补充来源证据是该篇的实际核验工作。这轮不新增自动全文抓取或把未取得的信息判真。
