# 整片节奏与旁白同步打磨 · 2026-11-11

本轮先检查真实视频的完整讲稿、时间线、各页边界及开头、中段和收尾画面，优先修复“旁白已开始解释用途，画面仍停在上一页”的叙事衔接问题。没有继续修改截图大小或图形布局。成功范围是一处有连续视频证据的换页改善，不是整片留存或全部节奏问题已经解决。

## 比较与取舍

现有基线已经有逐词对齐的页内强调。但“low 用途”所在语句被分给前一页，后页只能在自己的起始语句里生成强调。继续微调动画时长或高亮提前量无法解决页面归属错误，因此停止这条方向。

候选方案只利用分镜里已有的明确旁白短语：在同一原段落、同一章节、相同素材的相邻页面间，移动完整语音段的归属，保持内容和音轨不变。两页都必须有能唯一定位、且不交错的短语；找不到、重复或交错时保留原安排，不猜语义、不新开模型调用。候选片段显示用途页能与用途讲解一起开始，随后自然转到 high；才将方案接入生产编译。

没有试验或接入统一加速旁白、增加切页频率、给静态插画随机加运动；这些不作为已比较成功的方案。没有为已发现的那句中文或某个视频 ID 写专门分支。

## 自动接入与验证范围

`g2/scene_boundaries.py` 从已有视觉对象、代码、图表、关系图及素材分镜的明确短语取得归属范围，在满足范围时选离原切点最近的边界。只移动完整 TTS 语句，仍由既有编译器计算停顿中点，再复用逐词对齐产生页内强调。调整后不产生不足两秒的新页面。不存在强行覆盖全部叙事结构的目标。

`g2/explanation.py::compile_storyboard` 在生成场景和节拍之前自动调用这一逻辑。没有新增模型请求、配置开关或人工确认；原任务与原成片保持不变。生产路径保存 `scene-boundaries.json`，写出调整后的分组和正常分镜。界面、截图渲染器及复杂关系图代码本轮未改。

新增测试以构建命令、季度图表等不同内容验证提前切页、延后切页、跨语句短语；也验证重复/缺失/交错短语、跨章节/段落/素材以及过短页面不被强行调整。不是只检查当前 low/high 视频。

真实跨结构回放：教程 13 页、工具对比 16 页、未参与调试的 Qwen Code 长片 44 页，正常编译的完整改前/改后输出均完全一致。它们证明本次改动未扰动这些既有节奏，**不证明这些片子都已经变得更好**。目前只有一处真实正向修复案例；更广泛的收益仍需后续成片验证。

## 完成边界

本轮完成的是从真实整片中定位问题、通过连续片段验证、正常自动接入、完整成片重渲染及跨结构回归。没有以测试或静态截图替代视频交付。
