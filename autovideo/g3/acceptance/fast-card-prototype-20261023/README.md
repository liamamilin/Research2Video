# 《续航手机最抢眼，五件新品变化速览》独立快速卡片样片

用户要求：先用这篇稿件看快速版效果，暂不接入现有链路。

## 交付

- 最终视频：`g3/data/fast-card-prototype-20261023/topic-digest-v5/video.mp4`。
- 全长 212.9 秒（约 3 分 33 秒），1920×1080，30fps，H.264 VideoToolbox / AAC 48kHz 双声道。
- 24 页正文信息卡片，加片头、来源卡、片尾，共 27 页。配方绿色品牌、章节导航、重点信息、判断边界、33 条逐句字幕及提示音。
- 设备为代码绘制的形态示意，不使用未经核实的产品照片；耳机使用入耳式示意。耳机章节的来源待核实提示保留。
- 保持原定稿全文和原音色、原旁白，不重新写稿或调用外部分镜、图片、配音服务。

## 实验边界

这是一个独立样片脚本，不创建 AutoVideo 或研究系统任务，不修改数据库、配方、API、worker、现有渲染器或默认出片方式。所有运行资产放在独立的忽略目录中，原成片不变。

本次 **页面要点与版式为人工编排，旁白复用已生成音频**。`qa.json` 中的计时从页面内容和既有音频已经准备好之后开始，包括 PNG 卡片生成、音频装配、FFmpeg 合成及媒体 QA；**不包含编辑要点的人工时间，不包含重新合成 TTS，不是全自动冷启动文稿到视频总耗时**。不能直接拿这个数字与此前约 10 分 45 秒的完整出片时间比较。

与原视频相比，快速版用预绘制卡片、原生字幕及硬件编码合成，没有浏览器逐帧渲染和复杂逐元素动效。本次先验证观感与独立合成路径；自动画面要点提取、快速 TTS 和批量吞吐尚未接入或压测。

## 复现

从 AutoVideo 根目录运行，使用新的输出目录以保留已有结果：

```sh
python3 g3/acceptance/fast-card-prototype-20261023/build.py \
  --output g3/data/fast-card-prototype-20261023/NEW --stage prepare
python3 g3/acceptance/fast-card-prototype-20261023/build.py \
  --output g3/data/fast-card-prototype-20261023/NEW --stage encode
```

页面文案见 [pages.json](pages.json)。原生合成必须先 `fps=30` 再绘制 ASS 字幕；仅在输出设置 `-r 30` 会在滤镜之后复制静态帧，导致字幕冻结或停留在淡入状态。
