## 验收中发现并处理

1. 文章没有 `report_path`，共享迭代面板曾禁用重写。已修正入口条件和说明，并补充前端回归。
2. 信息文章 v1 扩写了原文没有的观察时长和总结，真实忠实度审校未通过。收紧通用改编规则后生成 v2，独立复审通过；v1 原样保留。
3. 信息文章首片 `e20bee522c814d57a62a98b3a7e1a5bd` 有重复温度卡，后卡未再次标常压。收紧文章共用画面提炼要求后重跑同一 v2 稿，最终片只在带「常压下水的沸点」的卡上展示 100℃。首片、请求和日志均保留。
4. 矩阵只覆盖部分包装配置时，文章入口须继续继承配方其他项；没有真实来源链接时须移除不成立的「主要来源见简介」。已有自动回归和实际散文样片证据。
5. 畸形来源网址（例如不闭合的 IPv6 地址）原先可能抛出未处理异常，现按输入错误返回 422，不产生稿件。

- `science_daily` 原配置的 1.25 倍播放速度照常继承，音高、字幕和动效同步；这是现有矩阵设置。
