# 数字主体空等：2026-11-12 第二轮

当前状态：**生产入口已验证，本轮数字页空等优化完成**。结论仅限已验证的数字页阅读体验，不代表整片节奏或涨粉效果已解决。

## 观看问题与目标

真实自动单条 `80a78a63-09d5-4b18-b203-3a24c3a4d56d` 的 21.6–55.3 秒：
“近100%”数字页从 26.87 秒开始，但主体等到约 38.7 秒的后一次中文提及才开始出现。
前面英文引述已经说出这个比例，画面却只有说明，观众无法在主画面确认数字。
同段的“3天”“6–12个月”也有短一些的空等。

目标是让数字、单位和上下文从数字页进入时就能一起阅读。此目标不等于增加动效、修好数字匹配算法，也不代表解决整片节奏。

## 对照与取舍

实验保持自动生成的稿件、分镜、旁白、原始时间轴完全相同，只替换可信渲染器的数字入场。

| 表达 | 观察与决定 |
| --- | --- |
| 原版：等到 line:0 cue 才显示数字 | 27.6–38.6 秒主数字仍空白；保留为对照。 |
| 数字与单位、说明同时入场 | 原声讲解开始时有完整阅读对象；采用。 |
| 先显示数字，到原 cue 再变绿 | 也能消除空白，但单一主体的变色未带来额外理解收益；舍弃，不扩展。 |

未参与调试的真实整期 `9fc7f436-650a-49f1-9ede-98cc5c078092`，519.3–545.4 秒的 Decisions API 小数价格、概念解释、成本比例是结构不同的保留样例。沿用同一改法，无参数调整：0.10 和 20% 在页面进入后即可与单位、比较对象一起阅读；中间概念页和后续稳定状态保持一致。

AMD 33.7 秒、1011 帧；保留样例 26.1 秒、783 帧。所有实验完整解码通过；同稿同分镜、帧数一致，解码音频相关系数均为 1.0。顺序查看了 AMD 9 页和 Decisions 7 页每秒采样，保留原声 MP4。本轮没有连续人工听完整音轨，不把图像采样检查描述成连续观看测试。

补充 MP4 回归：五个延迟 cue 数字页在场景开始后 0.7 秒均已有主数字，原版同区域为空；中间未改动概念页的 8 秒、240 帧对照 SSIM 为 0.999948，残差来自压缩，顺序检查未见表达变化。这些数值用于确认影响范围，不作为视频质量分。

## 未成功尝试、纠正与剩余问题

“到原 cue 再变色”没有额外收益，未接入。为旧版加同一章节导航时，对照辅助脚本的 FFmpeg 默认成了 25fps，帧数检查拒绝该中间片；显式保留原 30fps 后重做并通过。失败中间片、原始渲染和命令都保留，生产代码与实际视频没有因此改变。

曾从缩小拼图误判 580–584 秒概念卡边缘裁切。直接复核实际 MP4 的 580.37–584.37 秒帧后确认文字完整，**撤回裁切判断**；`production-emeans/visual-review.json` 及复核图片同步保留更正。

真实整片中仍值得研究的问题：18.4–38.43 秒约 20 秒静态导读；60–76 秒密集关系索引的小字阅读负担；326–332 秒图表已有数值但类别标签到约 334 秒才出现；多段概念卡表达重复。它们不是本轮新增的数字入场行为，也没有被本轮解决。后续应继续从这些实际区间比较更简单的表达，不沿着数字入场方式无限扩张。
