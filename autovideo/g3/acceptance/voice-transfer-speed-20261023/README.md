## 修改与计时结论

配音使用现有 VoxCPM2 的编译入口，同一进程中只缓存参考音频的确定性编码，左／右补齐分别保存，续接音频继续逐句计算。前三句独立对照 WAV 完全一致，26.184 → 25.967 秒，短样本收益很小，见 [微测量](voice-micro-benchmark.json)；完整稿件的实际收益以上表为准。

新增按完整章节保存的真实音频缓存。章节边界会重置参考音色，因此只复用整章，不跨续接依赖猜测复用单句。键绑定模型权重、参考音频、分词器、语音实现、文字规范化、合成设置和有序文本；恢复前逐份核对 WAV 大小、SHA、采样格式和质量记录。任何修改或损坏均重新合成对应章节。缓存最多 512 MiB，写入预算不足或缓存故障时仍正常合成；原始任务文件独立保存。可用 `AUTOVIDEO_G2_VOICE_CACHE=0` 在直接 G2 运行时关闭缓存做对照。

回传使用单任务 HTTP 连接池，最多 4 路文件复制；重复文件名拒绝，失败时等本批写入结束再重试，只复用通过大小与 SHA 的完整文件。最后一次失败后不再额外等待。新增提交、轮询、发现远端完成、文件复制、逐文件耗时与进程运行次数的持久化记录，API 返回 `timings`，成片页显示实测总耗时和回传时间。

**上轮约 116 秒的差额不能当作下载耗时。** 同一份已有成片的 25 个文件、41 MB 实测：原逐文件新连接 0.315 秒，连接复用并发 0.107 秒，见 [复制对照](copy-benchmark.json)。旧研究服务日志在 `17:28:01` 记录了恢复一个出片任务，随后 `17:28:02` 完成；与等待心跳过期后的恢复相符。现以进程锁决定能否接管，启动和巡检立即检查，活跃跟踪者由锁保护，不再为已退出的进程固定等待 120 秒。两次本轮正式出片均为单次跟踪、轮询错误 0 次。当前仍有最多约一个普通轮询周期的完成发现等待；复制耗时也随本机负载波动，实测第二次为 5 秒，未声称所有复制都只需 0.1 秒。
