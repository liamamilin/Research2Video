# 整期节目导航验收

研究端通过原生 `episode.items[].{title,chapter_indexes}` 提交节目条目，原有 narration chapters、配音与画面选择沿用。公共制作阶段按实际配音与镜头帧区间生成当前条目、下一条和分段进度；标准、快速混合共用，不拼接多条既有视频。

导航位于 1920×1080 的底部 `y=1024..1080`，字幕区域结束于 `y=1020`。保存合成前原片，音频流直接复制。`episode-navigation.json` 记录内容关系；最终播放跳转组合包装后的 `chapters.json`，覆盖片头、片尾和倍速偏移。

完整离线回归：970项通过、1项跳过。同一篇八内容总稿，快速混合information_cards与标准object_showcase均产生717.233秒、1920×1080真实MP4，两版完整解码、16张内容采帧、七处边界前后14张画面和真实播放器八项跳转／时间跟随通过。标准版125段配音全部缓存复用。

快速版导航前后整个音频流哈希相同；标准版33341个保留AAC包逐包相同，仅省略末帧之后的一个静音填充包，省略部分解码峰值为0，不声称标准版整个流哈希相等。原片与所有尝试保留。见 `fast.json`、`standard.json`。未公开发布，不声称主观听审过全片。

完整实施与验收记录见研究端 `spec/acceptance/episode-programmes-20261031.md`，实际运行资料在研究端 `state/validation/episode-mode-20261031/`。
