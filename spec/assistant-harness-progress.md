## 验收中修复的实际问题

- macOS 的 /var 与 /private/var 路径别名导致独立 worker 误判输出越界；统一真实路径并拒绝目录外符号链接。
- 上游重跑失败后仍可能读取磁盘旧报告；下游保持过期并阻止重同步旧产物，完成数也排除过期阶段。
- 报告元数据中的 job_name 被误当作真实任务引用；引用现在按领域生成，已生成但未入索引的文件也有可核验路径。
- provider 切换可能残留旧请求头；通过预设同步替换，私密值不经过模型。
- 重复启动失败可能覆盖活跃实例身份；运行身份/PID 改为接收 HTTP 后发布，并增加重复启动回归。
- 构建清空 dist/assets 时与后端初始化测试并发导致一次环境竞争；最终构建和后端回归顺序执行。
