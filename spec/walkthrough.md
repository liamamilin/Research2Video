# 试用说明（一页）

地址：http://192.168.2.226:8775/（局域网内，手机也行；端口是 8775，8765 被别的程序占用）。服务关了会在你打开网址时自动拉起，第一次可能要等约 1 分钟。

## 一条视频怎么走（顺序）

1. **生成选题**：快讯发现每天自动跑一次（约 20 次搜索）；选题页在「快讯」类格子旁有「生成今天的选题」按钮，运行中会置灰，点之前会确认搜索额度。情报轮次已停，深度解读的选题停在最后一期。盘点用快讯条目合成，对比只能手填。
2. **管理选题**（`/topics`）：顶部是内容矩阵（类型 × 受众），点一个格子看它的选题。每条带事件日期、评分、适合的格子（写过的 ✓）；「偏旧」表示事件超过 5 天；「不写」可撤销，标了的不进待写数，自动流水线也不挑；可选历史报告日期。
3. **写稿**：点「用这个写稿」；盘点在盘点格子里勾 2–10 条再点「合成一期盘点」；也可以在首页「自动流水线」卡片里设每个格子写几条，一键开始，或存为每周计划的内容。研究花搜索额度，3–10 分钟。
4. **研究、写稿、审计**：自动，中断后从断点继续。草稿先出来，事实/理解/表达三项审计随后补。
5. **看标签**：每篇稿子带可信度标签（有出处可信、部分无出处、未审计、口播有问题、有待核实、有严重问题）。只提示，不拦；流水线直接定稿并出片。有待核实的会写明是哪一段。
6. **看片**（`/publish` 或详情「成片」）：成片 15–30 分钟；文件在 `state/video_renders/<render_id>/video.mp4`。带「有待核实」「有严重问题」「未审计」的先核对再发。
7. **发布**：系统不发布任何东西。去 B 站手动传，回详情页「发布」页签记录链接和日期。

## 页面

| 页面 | 用来做什么 |
| --- | --- |
| 视频看板 `/` | 阶段计数、需要你处理的成片和失败、自动流水线（计划、最近一批、按格子设数量） |
| 选题 `/topics` | 内容矩阵、生成选题、选题管理（见上） |
| 文稿 `/video` | 新建文稿和全部文稿列表（状态、格子、可信度、来源、时间范围筛选，归档） |
| 成片与发布 `/publish` | 已定稿文稿的成片、标签、发布链接、快讯复核 |
| 助手 `/ask` | 用说话的方式查文稿、选题，开始写一篇，也能找外部参考视频（B 站、YouTube，只给链接） |
| 研究引擎 | Jobs、情报轮次、报告、周期调度，原来的页面 |

## 花时间或额度的操作

- 生成选题：约 20 次搜索，约 20 分钟。
- 每条研究：几次到二十次搜索，3–10 分钟；盘点不重新研究。
- 发布前复核（快讯）：约 4 分钟，一次搜索额度；手动点。
- 成片：15–30 分钟（AutoVideo）。
- 免费审校模型对长稿常超时，超时的稿子会标「未审计」。

## 格子验证状态

- 真实跑过并出过片：开发者受众的快讯、一个知识点（用快讯条目）。
- 实验：普通用户的三种、盘点、对比；深度解读选题停在 09-29。

## 还没做

- 自动发布：没有，永远只有你发布。
- 新增选题来源（如 GitHub 热门）：需要新建发现任务，等你确认搜索额度。
- 在界面里编辑矩阵（加类型、加受众）：只读，改要动 `config/video_matrix.yaml`，会影响提示词和测试契约。
- 事实审计覆盖有限：对一份定稿样本只找到约三分之一的人工改动，约一半提示是误报。
- B 站章节时间戳格式没有官方来源，上传时请自己核对。
