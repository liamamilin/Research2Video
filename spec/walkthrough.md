地址：http://192.168.2.226:8765/（局域网内，手机也行），账号 admin。服务关了会在你打开网址时自动拉起，第一次可能要等约 1 分钟。

## 每个页面做什么

| 页面 | 用来做什么 |
| --- | --- |
| 视频看板 `/` | 每个阶段有几篇；「需要你处理」列出待审校的草稿、待发布的成片、需要复核的快讯、失败的任务，点一条直接进文稿 |
| 选题 `/topics` | 看今天快讯的条目和情报轮次推荐的选题，已写过、已发布的有标记；「用这个写稿」会带你到文稿页并框出这条 |
| 文稿 `/video` | 新建文稿（选栏目格子、选题、视频形式）和全部文稿列表（可按状态、栏目筛选）；进某一篇后有四个页签：稿件、审校、成片、发布，页面上方「下一步」告诉你现在该做什么 |
| 成片与发布 `/publish` | 所有已定稿的文稿：成片到哪了、能不能发、发布链接、快讯该不该复核 |
| 助手 `/ask` | 用说话的方式做上面所有事：查文稿、查选题、开始写一篇、定稿、记录发布链接；也能管研究任务和设置 |
| 研究引擎（侧边栏分组） | 研究总览、Jobs、情报轮次、报告、周期调度：研究和后台，原来的页面都在，地址没变 |

## 哪些操作花时间或额度

- 新建文稿：研究 3–10 分钟、消耗搜索额度；之后写稿；短稿还有事实/风格审计，用免费审校模型会慢，但草稿先出来，审校结果之后补上。盘点和对比不重新研究，写稿几分钟。
- 发布前复核（快讯）：约 4 分钟，消耗搜索额度；手动点，24 小时后会提醒。
- 成片：15–30 分钟（AutoVideo）。
- 换风格重写：约 10 分钟，不重新调研。
- 助手创建、复核、成片、换风格前会先说明耗时。

## 哪些格子验证过，哪些还是实验

- 已验证（真实跑过、成片过）：开发者受众的 深度解读（长）、快讯（短）、一个知识点（短）。
- 实验（能用，但没有真实成片过或样本很少）：普通用户受众的三种、盘点（开发者）、对比（开发者）。盘点已真实写过两次稿，最近一次段落长度合格；对比没有真实跑过。

## 还没做、你要知道的

- 不会自动发布到 B 站，任何地方都没有自动发。「记录发布」只存你给的链接和日期。
- B 站章节时间戳的格式没有官方来源（只有第三方说明），发布包里已标注，上传时请自己核对。
- 事实审计覆盖有限：对一份定稿样本，只找到约三分之一的人工改动，约一半的提示是误报；风格审计偏严，盘点里常有一批「信息点堆叠」必须改。
- 短稿的规则检查里有几条「必须改」是噪声（数字多、短横线区间等），已定稿的文稿里默认折叠。
- 助手只查内部数据（我们自己的文稿、选题、成片、发布记录），不上网找视频；自动创建只到草稿，定稿由你决定。
- 看板上有一些旧的测试文稿，还没有归档功能。
