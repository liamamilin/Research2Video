# 上手指南和最佳实践

地址：http://192.168.2.226:8775/（局域网内，手机也能用）。服务关了的话，打开网址会自动拉起，第一次要等 1 分钟左右。

这份说明先讲一次完整的上手，再讲日常怎么用最省事、最省钱。更细的规则见各 spec 文件（文末有索引）。

---

## 1. 先认识五样东西

```
选题 ──▶ 研究报告 ──▶ 文稿（几个版本）──▶ 成片 ──▶ 你手动发布
            ▲               ▲
            └──── 配方：一种视频的做法（怎么调研、写给谁、写多长、出成什么样）
```

| 东西 | 在哪看 | 一句话 |
|---|---|---|
| 选题 | 「选题」页 | 想做的一件事。来自发现 Job，也可以手动添加 |
| 研究报告 | 文稿页「同一份研究」、「报告」页 | 一次调研的结果，**一份报告可以写好几篇**；任何报告都能直接「写成视频」 |
| 文稿 | 「文稿」页 | 一篇稿子。每次重写、改稿、换风格都会存成新版本，旧版本都保留 |
| 成片 | 「成片与发布」页 | AutoVideo 用定稿的那一版做的视频 |
| 配方 | 「文稿配方」页 | 一种视频的做法：快讯、一个知识点、深度解读、盘点、对比 |

每篇文稿都要走五步：**调研 → 写稿 → 审计 → 定稿 → 出片**。文稿页顶部的步骤栏会显示走到了哪一步、卡在哪一步。

## 2. 第一次上手：做一条快讯（推荐路线）

快讯跑通全程的次数最多（6 条成片），又便宜又快，适合第一次用。

1. **看板首页**（不花钱）：看各阶段有多少稿子。如果顶部有「自动化异常」卡片，先看一眼。
2. **选题页**：点「快讯」那一类格子。
   - 已经有选题，就直接用；
   - 没有，点「生成今天的选题」。要花搜索额度（约 20 次），大约 20 分钟。跑的时候按钮是灰的，别在 Jobs 页再手动跑一次。
3. 挑一条没写过的选题，点 **「用这个写稿」**，再点「写这一篇」。调研加写稿大约 3–10 分钟，可以离开页面。
4. **打开这篇文稿**，看三处：
   - **步骤栏**：哪一步完成、哪一步在等你；
   - **可信度标签**：从好到坏依次是「有出处可信」「部分无出处」「未审计」「口播有问题」「有待核实」「有严重问题」；
   - **「审校」页签**：具体哪一段有什么问题。
5. 稿子要改，就点「编辑」，改完点「保存为新版本」。
6. 点 **「定稿 vN」**，然后到「成片」页签点 **「用定稿 vN 出片」**。成片要 15–30 分钟。
7. 到 **「成片与发布」** 页看片。去 B 站手动上传，回到文稿的「发布」页签复制标题和简介，记下视频链接和发布日期。

**系统不会替你发布任何东西。**

## 3. 最佳实践

### 3.1 省搜索额度：先用已有的研究

- 想就同一件事再做一种视频（比如快讯之后再做一个知识点），在文稿页「同一份研究」里选一个配方，点 **「用这份研究再写一篇」**。不再调研，不花搜索额度。
- 研究引擎任何一个 Job 跑出来的报告（「报告」页里打开它），都可以点 **「写成视频」**：选配方，题目不填就用报告标题，不用先建选题，也不再调研。快讯发现这类选题来源报告除外，它的条目去选题页挑。
- 稿子写得不好，用步骤栏的 **「重写」**：用同一份报告重写，不再调研。
- 只有选题本身变了，才新建文稿重新调研。

### 3.2 改稿：选对方式

| 你想 | 用什么 | 花费 |
|---|---|---|
| 改几句话 | 「编辑」→「保存为新版本」 | 不花钱。改完后模型审计不会自动重跑，审计一步会显示「改过稿子，模型审计没有对这一版重跑」 |
| 整篇重来，写法不变 | 步骤栏「重写」 | 写稿模型 |
| 换深浅或语气（只有深度解读能换） | 「风格」→「用这个风格重写」 | 写稿模型，约 10 分钟 |
| 只重查事实（一次写成的稿子） | 步骤栏「重跑审计」 | 审校模型 |

已经定稿的稿子，重写或换风格成功后会回到草稿，要重新定稿。旧的定稿和成片都还在。

### 3.3 深度解读：先看方案再写（可选）

深度解读用的是「五步改编」：拆事实 → 定方案 → 写稿 → 审校 → 修改。想在写稿前先把关方案：

1. 「文稿配方」页 → 打开 `deep_dive` → 在 `writing:` 下面加一行 `pause_after_plan: true` → 保存。
2. 之后**你手动写的**深度解读，定好方案就会停下，状态是「方案待确认」，首页的待办里也会出现。
3. 在文稿页读方案，三选一：
   - 改核心问题、主旨、开场钩子、每节的标题和要点，然后点 **「确认并写稿」**（不改就直接确认，写出来和不暂停时一样）；
   - 写一句意见，点 **「带意见重做」**（只重做方案，花得少）；
   - **「放弃」**（不花钱）。

自动流水线的稿子永远不会停在这里。不想用了，把那一行删掉就行。

### 3.4 看标签决定发不发

标签只是提示，不会拦住你。自动流水线不管标签是什么都会定稿、出片。发布前：

- **有严重问题 / 有待核实**：先看「审校」页签里点名的那几段，核对后再发；
- **未审计**：免费审校模型对长稿常常超时。可以对一次写成的稿子点「重跑审计」，或者自己核对；
- **口播有问题**：多半是读起来拗口，听一遍成片就知道。

快讯的「发布」页签里还有一个 **「发布前复核」** 按钮（约 4 分钟，上次用了 6 次搜索），用来查消息有没有过时。「成片与发布」页会提醒哪些快讯该复核了。

### 3.5 自动流水线：让它批量干活

首页「自动流水线」卡片：

- 设好每个格子写几条，点开始，它会自己挑题 → 写稿 → **自动定稿 → 自动出片**，只写到成片，不会发布；
- 也可以存成每周计划，到点自动跑。周计划在「周期调度」页的「其他定时任务」里能看到；
- 一批里每条走到哪一步、为什么停住了，卡片上都有写。

适合量大、标准稳定的快讯。深度解读建议手动写，因为它慢、贵，还值得先看方案。

### 3.6 出错了怎么办

| 看到 | 做什么 |
|---|---|
| 步骤栏「调研 失败」 | 点「从断点继续」。调研 Job 已经跑完的报告会直接拿来用 |
| 「写稿 失败」 | 点「重写」 |
| 「审计 没跑完」 | 一次写成的稿子点「重跑审计」；深度解读的审校是写稿的一部分，要重来就点「重写」 |
| 首页「自动化异常」 | 每条都写了原因，看过点「知道了」 |
| 想知道调研到底搜了什么 | 调研进行中时，文稿页有「查看研究任务的实时日志」；调研结束后去 Jobs 页找 `video/` 开头的那个 Job |

服务重启会打断正在写的稿子：已经写好的版本不会丢，按上面的办法重跑那一步就行。

### 3.7 想换一种做法：改配方，别改代码

- 「文稿配方」页：每份 YAML 就是一种视频的完整做法。**先「复制为新配方」再改**，原来的不动；
- 保存前会校验，有错不会保存；删除前会先备份；
- 调研方式和出片设置是共用部件，改一个部件，所有引用它的配方都会跟着变，保存前会逐个检查。

## 4. 花钱和花时间的操作

| 操作 | 花什么 | 多久 |
|---|---|---|
| 生成今天的选题（快讯发现） | 约 20 次搜索 | 约 20 分钟 |
| 新建文稿并调研 | 几次到 20 次搜索，加写稿模型 | 3–10 分钟 |
| 用已有研究再写一篇 / 重写 | 写稿模型（不搜索） | 几分钟；深度解读约 10 分钟 |
| 重跑审计 | 审校模型 | 几分钟 |
| 带意见重做方案 | 写稿模型（只重做方案） | 比写一整篇快 |
| 发布前复核（快讯） | 约 6 次搜索 | 约 4 分钟 |
| 出片 | AutoVideo 机时 | 15–30 分钟 |
| 看、编辑、定稿、放弃方案、归档 | 不花钱 | — |

## 6. 现在的情况和限制（2026-10-20）

- **出过片的配方**：快讯、一个知识点、深度解读。标「实验」的配方（普通用户的三种、盘点、对比）还没出过片；盘点写过 5 篇草稿。
- **深度解读没有新选题**：它的选题来自情报轮次第 07 步，而每天 06:00 的情报轮次 9 月底就停了（备份还在，可以恢复，恢复后每天要花搜索额度）。可以在「情报轮次」页手动跑一轮，或者手动添加选题。
- **发布记录还是 0 条**：发布这一环还没有真正用过。
- **事实审计有限**：在一份定稿样本上，它只找出了大约三分之一的人工改动，提示里约一半是误报。别把「有出处可信」当成保证。
- B 站章节时间戳的格式没有官方说明，上传时请自己核对。
