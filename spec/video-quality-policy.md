# 视频质量优先规则

> 2026-10-24：默认生成已按唯一目标重置，见 [当前流程](video-goal-first.md)。下文保留旧实现及试验历史，不作为新生成的约束。

2026-10-23：适用于研究、一次写稿、五步改编、审校与自动出片。逐项修改清单见 [video-editorial-quality.md](video-editorial-quality.md)。目标是有价值、有主线、好听的文稿；旧实验记录中的数量门槛不再执行。

## 必须保留的底线

- 不编造事实、数据、来源、测试经历或行动效果；假设、推测、厂商自述和冲突保持原有性质。
- 引用可追溯到实际取得的资料。保留会改变当前结论的归属、单位、比较与适用条件；不要求每项数据朗读全部模型、硬件和实验参数。
- 清楚归因的厂商自述可以使用；缺少第三方复测本身不是错误或待核实理由。审校通过表示来源支持当前转述，不表示我们做过独立实验。
- 事实审计失败不算通过。已确认的事实或引用问题需要修复；未解决的保留具体原因，自动流水线暂停出片。
- 保留可解析的 JSON、有效事实编号、非空正文与当前中文配音兼容要求。视频标题 2–80 字、章节标签 1–32 字是 AutoVideo 接口约束，不适用于口播正文。

## 放宽为参考的要求

| 层面 | 当前行为 |
|---|---|
| 九份配方 | 保留各自视频定位；时长、节数、段长、条目数、动作数作为参考，不凑数量 |
| 公共提示词 | 不统一要求 15 秒钩子、40 字句子、两个数字或一个命令；开场、结尾、称呼、类比与回顾服从配方和理解需要 |
| 受众与风格 | 入门表达可以保留必要术语和原始计费口径；换算需有依据，不用通俗化掩盖条件 |
| 四份调研模板 | 使用配方传入的参考时长，不写死 60–90 秒；证据收集不随口播预算裁减，角度数量不设硬上限 |
| 讲述方案 | 不按时长限制事实条数，不强制 3–5 个目标或两步因果链；节数、角色及分节字数预算不再传给作者，也不再提示偏差；短稿也可选择五步改编 |
| 自动审校 | 观众评读和主编审校关注实际听感；具体主编问题和收听障碍优先进入有限轮次的整篇编辑，事实问题同时交给编辑处理，候选稿完整复核；意见可取舍，不作为通过门槛。取消密度、句长、回顾和词语配额的机械判定。测验与评分是参考；事实/引用问题及明确的内部资料备注需要修复 |
| 改写检查 | 字面参数遗漏作为复审线索，结合全文判断是否误导，不因删掉一个型号就自动恢复冗长原文 |
| 报告输入 | 不再静默截取前 60,000 字符，避免漏掉文末来源与限定；模型容量不足时记录失败，不把缺资料当核验完成 |
| 出片 | 已定稿正文逐字配音，使用 `duration_mode: content`，不按配方时长裁切 |

`minutes_range` 控制生产配置可选的参考目标，并非成片时长上下限。±15% 仍显示偏差，不阻断或启动压缩、扩写。技术超时、有限重试、并发和账户预算仍控制资源使用，不用于删减事实。

## 实现与验证

`core/video/policy.py` 定义来源核验说明与事实问题判定；作者只接收素材、创作目标与必要数据格式，写法保留在 `config/video_recipes/`、`config/video_parts/audience/` 和 `config/video_styles.yaml`。旧 `style_severity: must` 兼容读取，实际表达问题只提醒。

回归覆盖：超长且数字密集的稿件不被数量规则改写、结构偏差不重做、表达审计失败不妨碍事实审计、事实失败不能通过、超长报告文末不丢失、条件丢失仍拦截。历史文稿、评审和成片保留原记录；新规则用于后续生成或复审。

## 研究备注与观众文案

研究摘要未收录数据，不等于原评测、厂商或现实没有数据。写稿与改稿不能用「材料未给出」「没说明」回答观众疑问，也不能将它直接替换为「原评测未提供」。无证据时收窄或删除对应比较、推荐，缺口留在审校记录。

影响结论的官方归属、测试范围、比较方向和有限场景体验随相关意思自然交代，其余细节可放资料或简介。两条写稿路径及其审校共享这些规则；确定的内部资料备注进入修复流程，修复后仍存在时自动流水线暂停，不靠普通建议级别绕过。事实审计失败保留当前稿和待核实标记，不继续盲目改写。

本篇网页复核产生独立来源快照和新稿版本；原报告、旧稿、旧待核实记录及成片不覆盖。网页复核是本次验收工作，不代表系统已增加自动全文抓取功能。
